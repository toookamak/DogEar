D DogEar 扩展设置

填写 DogEar 服务地址与 Skill Token，保存即可连通。

Token 由部署方配置（wrangler secret put DOGEAR_SKILL_TOKEN），用于 Agent 与扩展保存接口。

Agent 接入说明

Agent 保存同一接口：POST <DogEar地址>/api/skill/save_bookmark， 头部带 Authorization: Bearer <Token>，能力发现见 GET /.well-known/capabilities。详见仓库 docs/modules/20260912_浏览器扩展与Agent接入.md。
