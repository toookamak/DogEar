# wiki 定稿目录（文件注册表）

`wiki/` 只放已经注册的定稿。往这里**新增、修订或删除**，须用户明确同意（见根目录 `AGENTS.md`）。

## 冲突顺序

1. [需求总纲](./DogEar-需求总纲.md) — 产品对错、过关标准
2. [技术总纲](./DogEar-技术总纲.md) — 工程蓝图、选型与边界
3. 模块定稿（本表下列「账本」「窗口」）— 表与接口的实现规格
4. `docs/modules/` 过程稿与细部 — 交互未决、执行计划
5. `docs/archive/` — 只追溯，不实现

同一件事，排在前面的赢。

## 本目录不放

- 执行计划、开发记录、待设计细部 → `docs/modules/`
- 过期稿、被替代的草案 → `docs/archive/`
- 界面视觉源 → 根目录 `DESIGN.md`（尚未建立时以原型为准）

## 以后怎么改这些定稿

1. 先在 `docs/modules/` 写修订草案，说明改哪条规则、为什么。
2. 用户确认后，改 wiki 对应文件、升文档版本、在该文件修改记录和本表登记。
3. 代码不得先于定稿改表含义或公共回执形状。
