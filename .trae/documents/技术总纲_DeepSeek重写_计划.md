## 3. 产出物与结构规划（新文档 v1.0\_DeepSeek）

- **文档头**：版本、日期、作者（DogEar，匿名）、关联 PRD v1.0.7、状态、术语口径说明。

- **写作风格**：产品-技术双视角，先讲清"为什么这么设计"（产品约束/取舍），再落到"怎么做"（架构/模块/数据/流程/接口/部署）；区分 **✅已定 / ⏳暂定 / 💡方向性 / ❓待决策**，不把 Draft 中"暂定/待设计"擅自写成已定。

- **拟定目录结构**（对齐范例骨架、按 PRD 重排章节，写作时可按内容微调）：

  1. 项目概述（背景/定位/核心目标/使用场景/非目标）
  2. 需求映射总览（核心/近期/愿景 → 功能→模块→技术落点）
  3. 系统架构（分层：接入层/服务层/数据层/同步层/内容层；端侧缓存+服务端真源；两种形态工作台/导航页/扩展）
  4. 技术选型（前端/服务端/存储/部署；标注已定与暂定来源）
  5. 核心数据设计（概念模型：Bookmark/Scene/Status/Folder/Tag/Archive/ArchiveJob/访问记录/操作日志/同步队列/回收站；属性分层：基础属性/内容信息/扩展属性）
  6. 核心流程设计（Capture 主流程、Async Metadata、AI 建议分流、Archive Job 生命周期、导航圈选/展示、备份/导出、同步与冲突）
  7. 接口设计（内部模块接口；Skill API + capabilities 自描述；第三方通道接口约束——Raindrop/S3/WebDAV）
  8. 异常与边界（第三方中断、429、抓取失败、冲突、私密与鉴权、日志）
  9. 构建与部署（双轨部署、多端数据策略、鉴权）
  10. 里程碑路线（M1-M6 方向性映射 + 与核心需求/近期/愿景的关系）
  11. 待确认/待决策事项（继承 PRD §09 与模块细部）
  12. 附录（术语表、PRD 章节索引、素材文档对照）
  13. 文档变更记录
