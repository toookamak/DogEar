# DogEar · 数据模型草案（方向性 v0.1）

> 不定技术方案（IndexedDB/SQLite/服务端均可），仅定义功能所需字段与关系，后续随技术方案调整。以 Raindrop 兼容为前提，本地可扩展。

## 1. 设计原则
- **本地为真源**：所有写先落本地，含 `sync_status` 与 `updatedAt` 用于同步
- **兼容 Raindrop**：新增维度（情景/时间/优先级等）用标签前缀约定，例如 `_status:unread` `_scene:work` `_priority:high`，不强制依赖 Raindrop 字段
- **轻/重分离**：使用存储（结构清晰）与备份存储（可舍弃日志/临时）不必完全一致
- **600 条基线**：按 600 条量级设计索引与分页，超量可分页/虚拟化

## 2. 核心实体（方向性）

### 2.1 bookmark（书签主数据）
| 字段 | 说明 | 备注 |
|---|---|---|
| id | 本地ID + raindropId（映射） | 本地生成，同步后绑定远端ID |
| url | 链接 | 必填，唯一性按 url 归一化判断 |
| title | 标题 | 抓取/用户改 |
| excerpt / aiSummary | 摘要 | AI 生成或抓取 |
| folderId | 所属文件夹 | 关联 folder |
| tags | 标签数组 | 含 `_status` `_scene` `_priority` 等约定前缀 |
| status | 未读/在读/已读/归档（由标签约定派生） | 方向性 |
| showInNav | 是否在导航页显示 | 工作台 `设置>导航页` 控制：`全部/按规则(或)/自定义/隐藏`，按规则先做或、自定义支持搜索筛选，持久化 |
| isPrivate | 是否私密 | 隐私标记 |
| favicon | 图标缓存 | 抓取缓存 |
| createdAt / updatedAt | 时间 | 用于排序与同步 |
| syncStatus | pending/synced/conflict | 同步态 |
| source | manual / skill / raindrop_import | 来源 |

### 2.2 folder
| 字段 | 说明 |
|---|---|
| id / raindropCollectionId | 本地与远端映射 |
| name | 名称 |
| parentId | 父级（若支持层级） |
| icon | 自定义图标 |
| sortOrder | 排序 |

### 2.3 tag
- 仅为标签字典（去重/归一），实际以 bookmark.tags 为准；支持相似标签归并建议（方向性）

### 2.4 page_tab（导航页页面标签）
| 字段 | 说明 |
|---|---|
| id | 本地ID |
| name | 名称（常用/开发等） |
| layout | horizontal / vertical |
| sortOrder | 拖拽排序 |
| filter | 该页对应的筛选规则（文件夹/标签/自定义） |

### 2.5 docker_items（导航页 Docker，本地配置）
| 字段 | 说明 |
|---|---|
| type | bookmark / folder |
| refId | 指向 bookmark.id 或 folder.id |
| order | 排序 |
| 备注 | 不写入 Raindrop，主网格删除时同步移除 |

### 2.6 operation_log（操作日志，有限保留）
| 字段 | 说明 |
|---|---|
| id / at | 操作ID与时间 |
| actor | user / ai / sync |
| action | create/update/delete/move/tag |
| targetId | 目标书签ID |
| before / after | 变更前后（用于回滚） |
| 备注 | 默认 5000条/30天，循环覆盖，用户可改与导出清理 |

### 2.7 sync_queue
| 字段 | 说明 |
|---|---|
| id | 队列ID |
| bookmarkId | 关联书签 |
| op | 操作类型 |
| payload | 待推送内容 |
| attempts / nextRetryAt | 重试 |
| status | pending/success/failed |

### 2.8 ai_memory（AI 记忆，服务端）
| 字段 | 说明 |
|---|---|
| id | 记录ID |
| signals | 分类/标签偏好、阅读习惯、文件夹逻辑、搜索模式等 |
| scope | 是否含隐私（可标记不入记忆） |
| updatedAt | 更新时间 |
| 备注 | 在 `设置>AI` 预览/重置，日常无需进此页 |

## 3. 关系简述
```
folder 1—N bookmark
bookmark N—N tag（通过 tags 数组）
page_tab N—N bookmark（通过 filter 规则，非硬关联）
docker_items → bookmark/folder（快捷方式）
bookmark 1—N operation_log / sync_queue
```

## 4. 同步与关联要点（方向性）
- **推送**：bookmark 变更 → sync_queue → 定时按限频推 Raindrop
- **拉取**：定时/手动拉增量 → 对比 updatedAt/lastSyncAt → 处理冲突（默认本地为准）
- **显示关联**：`showInNav` 由工作台写（`全部/按规则-或/自定义-搜索勾选/隐藏`），导航页仅读并做布局；导航页编辑（拖拽/页面标签/Docker）不回写 Raindrop；导航页开关关闭后 `showInNav/page_tab/docker_items` 均持久保留，重开即还原，无需二次确认
- **备份**：轻（bookmark 核心+tags/folder 通用格式）、中（+page_tab/docker/ai偏好等配置）、重（全量快照含 log/queue）

## 5. 索引与性能（方向性）
- 索引：url、folderId、tags、status、updatedAt、showInNav
- 600 条基线下列表/网格分页或虚拟化，搜索以本地标题/url/tags/备注为主，不做全文正文索引
