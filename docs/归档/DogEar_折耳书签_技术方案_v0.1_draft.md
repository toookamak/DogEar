## 2. 数据通道（输入 / 导出）

本章为从 PRD §3.0 / §4.2.9 / §5.2 **迁出的内容**。产品结论不得在此改写。

### 2.0 范围约束（已定）

- 不接任何第三方，产品完整可用
- 首次使用不引导登录 Raindrop，只引导数据管理选择（可跳过、可多选）
- 可选通道：**Raindrop**、**S3**、**WebDAV** 等
- Raindrop 只作 **输入源** 和/或 **导出方向**，不是默认双向持续同步
- 输入：首次可「进 Inbox」或「保持原路径」；**首次梳理之后，新来的零散记录进 Inbox**
- 导出：Link 级存档；**不带 Scene 等 DogEar 使用场景**；回收站默认不进存档
- 能连上本应用即可保存；第三方未配置或中断不阻塞保存
- 无 30 秒推 / 5 分钟拉的产品要求；不做双端 CRDT

### 2.1 Raindrop 作为输入源

#### 2.1.1 已迁出

- 读入 **Raindrop 同构字段**（与附录 C.1 对齐）：`link` / `title` / `excerpt` / `cover` / `type` / `collection` / `tags` / `note` / `important`，以及 `created` / `lastUpdate` / `broken` / `domain` 等派生字段
- 本地扩展抓取（`author` / `favicon` / `publishedAt`）Raindrop 无对应，输入时不依赖
- Folder / Tag 保持对方原样，**不把对方数据变成 Scene**
- 首次导入：用户选「进 Inbox」或「保持原路径」，可走导入梳理页
- 首次梳理完成之后：该输入源新出现的零散记录进入 Inbox，不自动按原文件夹归位

### 2.2 Raindrop 作为导出方向

#### 2.2.1 已迁出

- 目的是**存档记录**，不是镜像 DogEar 工作方式
- **写出**：Link 级同构字段（URL / 标题 / 描述 / 封面 / 文件夹 / 用户标签 / 标星等，见附录 C.1）
- **不写出**：Scene、AERR、导航圈选、AI 建议、Inbox 语义、`_status`、删除标签
- 回收站条目默认不进入存档
- 高亮 / 提醒 / 附件等无产品入口的字段：随通道保留、不做成功能（附录 C 观察项）
