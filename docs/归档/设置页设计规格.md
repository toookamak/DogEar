# DogEar · 设置页设计规格

* **日期**：2026-08-31

* **版本**：v0.2.3（已实施：用户迁回顶栏右上角、侧栏底部仅操作按钮、主题三选菜单；v0.2.2 侧栏顶部统计卡 + 三区锁定；v0.2.1 弹窗锁尺寸 60vw/80vh）

* **关联**：PRD v0.3.7 / [高保真原型规格.md](高保真原型规格.md) / [API.md](API.md) / [DATA\_MODEL.md](DATA_MODEL.md) / [COMPONENTS.md](COMPONENTS.md) / [同步引擎细化.md](同步引擎细化.md)

* **范围**：隔离前端原型（`dev/dogear-workbench`），纯 UI 原型阶段

***

## 1. 背景与目标

侧栏底部"同步设置 →"目前是占位按钮（无 onClick）。本轮将其升级为完整的**居中设置模态框**，承载四大功能区：

1. **备份与恢复** — CSV 轻档 / ZIP 全量导出与导入；WebDAV / S3 云端备份（手动 + 定时配置）
2. **Agent 接入** — BaseURL + Key，REST 先行（延续 [API.md](API.md) 合约），可配置限频防误删
3. **日志与回收站** — 历史操作查询；软删除回收站，可与主视图操作实时联动
4. **状态信息** — 收藏数量、空间占用、同步状态等概览
5. **Raindrop 同步** — Token 连接、定时/手动同步、同步队列、API 限频、同步日志（v0.2 新增）

**原型定位**：界面、交互与状态流转完整；文件生成、云端真实请求、真实定时**不落地**（模拟执行），留待 server 阶段。相关设计约束仍然对齐正式文档，避免返工。

***

## 2. 已确认设计决策

| #  | 决策项      | 结论                                                                               |
| -- | -------- | -------------------------------------------------------------------------------- |
| D1 | 实现范围     | 纯 UI 原型：模拟执行，不产生真实文件、不真实接云端                                                      |
| D2 | 页面形态     | 居中模态框（遮罩 + Esc / 点遮罩关闭），内含左列分区导航                                                 |
| D3 | 备份格式     | CSV 轻档（书签核心字段）+ ZIP 全量（书签+文件夹+设置+日志+回收站，manifest 清单 + 完成标记）；恢复可选 **合并导入 / 覆盖恢复** |
| D4 | Agent 协议 | HTTP REST 先行（延续 API.md 的 Bearer Token 合约），MCP Server 后补（本期仅预留扩展位与说明）             |
| D5 | 日志/回收站   | 与主视图操作实时联动（删除→进回收站、操作→写日志）                                                       |
| D6 | 入口       | 仅侧栏底部按钮（"同步设置"更名为"设置"）；头像+用户名移入侧栏底部，TopBar 头像按钮移除                                |

## 3. 布局与交互结构

### 3.1 入口（侧栏底部改造）

```
┌─────────────────────────────┐
│  sidebar-top                 │
│  ┌─────────────────────────┐ │
│  │ ▤ 本地资料库            │ │  ← 顶部统计卡：总收藏（三状态实时求和）+ 文件夹/标签数，无 600 上限
│  │    N 条收藏             │ │
│  │    N 个文件夹 · N 个标签 │ │
│  └─────────────────────────┘ │
│  ───── 资料库 ────────────── │  ← 分区分割线；三项带状态色圆点（琥珀/蓝/薄荷绿）
│  ● 收件箱 · ● 稍后读 · ● 已归档 │
│  ───── 文件夹 ────────────── │  ← 弹性撑满中段（占比较大），列表超高内部滚动
│  设计参考 · 工程与工具 · 文章与笔记 │
│  ───── 标签 ──────────────── │  ← 自动高度，贴侧栏底部
│  灵感 排版 阅读 效率 本地优先 前端 │
└─────────────────────────────┘

sidebar-foot：两端布局——左侧 `.sync-area` 预留**两个同步按钮位**（当前仅 ↻，将来放上传/下载），右侧 `[ ☀ 主题 | ⚙ 设置 ]` 文字分段控件贴右
· ↻ 单独图标按钮（同步中旋转）
· 主题/设置带文字标签的分段控件（段间单线分隔、无容器外框）；☀ 主题点击向上弹出**全宽菜单**（浅色/深色/跟随系统，SVG 图标 + 右侧单选圆点），宽度跟随侧栏、不超出屏幕
用户头像 + 名称移至 TopBar 右上角（.topbar-user）
```

* 主题三态：`ThemeMode = "light" | "dark" | "system"`；"跟随系统"监听 `prefers-color-scheme` 实时切换 `data-theme`，选择持久化 localStorage。

* TopBar 右侧为 `.topbar-user`（头像 + 用户名）；侧栏底部 `.foot-actions` 只放操作按钮（同步 / 主题菜单 / 设置），分段控件带段间分隔线。

* Sidebar props 增加 `onOpenSettings`，AppShell 持有设置模态开关状态。

* 存储指示：移除侧栏底部"本地资料库 284 / 600 + 进度条"（无 600 限制），改为顶部实时统计卡；总收藏=待整理+稍后读+已归档 求和。

### 3.2 设置模态框

居中模态，宽为屏幕 **60%**（`width: 60vw`）、高为屏幕 **80%**（`height: 80vh`），切换分区窗口尺寸不变，内容区内部滚动；背景遮罩 `.modal-scrim`。

```
┌─────────────────────────────── 设置 ─── [×] ─┐
│ ┌─────────┬───────────────────────────────┐  │
│ │ 状态信息  │   （分区内容区）                │  │
│ │ Raindrop同步│                             │  │
│ │ 备份与恢复│                               │  │
│ │ Agent 接入│                               │  │
│ │ 日志     │                                │  │
│ │ 回收站   │                                │  │
│ └─────────┴───────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

* 左列分区导航（6 项），点击切换内容区，激活项高亮；顶部红点徽标指示"N 条冲突/N 条回收站待处理"（若启用）。

* 关闭：右上角 \[×]、遮罩点击、Esc（复用现有全局 Esc 通道，若需扩展）。

* 危险操作（覆盖恢复、彻底删除、清空回收站）进入**确认态**：按钮变警示色 + "再点一次确认"；必要处要求输入确认词。

## 4. 分区详细规格

### 4.1 状态信息

| 区块   | 内容                                                                                                            |
| ---- | ------------------------------------------------------------------------------------------------------------- |
| 收藏统计 | 总收藏数（mock 284）、待整理/稍后读/已归档 分布、本周新增、来源分布（AI / extension / raindrop）                                            |
| 空间占用 | 书签/文件夹/日志/回收站 条目数 × 估算体积、"本地资料库 284 / 600"、百分比条                                                               |
| 同步状态 | 状态灯（空闲/同步中/成功/失败）、上次同步时间、队列长度、速率四项（条/秒、时延、成功率、429 次数）、**立即同步**按钮（复用现有 `runSync`）；推送/拉取间隔等配置已移至「Raindrop 同步」分区 |
| 数据安全 | 密钥等敏感项说明（API Key 仅显示一次）、数据仅存本地提示                                                                              |

> 数据来源：由 `useBookmarks` 派生 + `useSettings` 合并。同步速率沿用原型现有模拟值，不新增真实采集。

### 4.2 备份与恢复

**本地备份区**

* **导出 CSV（轻档）**：书签核心字段（标题/URL/摘要/标签/文件夹/状态/时间/来源），演示进度 0→100% → 成功 Toast（显示条数）；模拟下载。

* **导出 ZIP（全量）**：包含书签+文件夹+设置+日志+回收站；演示进度 → 成功 Toast（显示条目数、生成时间、估算体积）；提示"ZIP 内含 manifest + 完成标记"。

* **恢复**：点击"从文件恢复"→ 文件选择（仅 UI，选后模拟解析进度）→ 弹**恢复方式选择**（合并导入 / 覆盖恢复）→ 二次确认（覆盖恢复需输入 `restore` 确认词）→ 模拟执行 → Toast。

  * 合并导入：新增条目追加，冲突（同 URL）提示"保留本地/采用备份"，沿用数据模型冲突处理语言。

  * 覆盖恢复：先展示"将替换 284 条数据"警示 → 确认后模拟覆盖。

**云端备份区**（参照 inkstone：多目标、凭证加密、手动+定时）

* 备份目标列表（mock 预置 1 个 WebDAV + 1 个 S3 示例，可增/删）。

* 新增目标：类型选择（WebDAV / S3）→ 表单字段：

  * WebDAV：服务器地址、目录路径、用户名、密码

  * S3：Endpoint、Region、Bucket、Path Prefix、AccessKey、SecretKey

  * 密码/密钥输入框：占位显示 `••••••••`（隐藏明文），有"显示/隐藏"切换

* 每个目标操作行：**连接测试**（模拟：成功/失败 + 错误信息）、**立即备份**（进度模拟）、**恢复**、**启用开关**、**删除目标**（确认）。

* **定时备份**：总开关 + 频率选择（手动 / 每天 / 每周）+ 上次成功时间 + 最近快照大小展示。

* **备份历史**列表：时间、类型、目标、结果（成功/失败）、大小（mock 数据倒序）。

### 4.3 Agent 接入（REST 先行）

| 分组     | 控件                                                                                                                                 |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 服务开关   | 启用 / 停用 Agent 服务（总开关），默认关                                                                                                          |
| 连接信息   | Base URL（默认 `http://localhost:3000`，可编辑）、Agent 名称（可选）、**API Key**：生成/轮换按钮 → 弹层显示一次 + 复制按钮 + "请立即保存"提示                              |
| 能力权限   | 开关组：`查询`（搜索/列表）、`新增`（保存书签）、`编辑`（更新标题/状态/标签/文件夹，默认关）、`批量整理`（experimental 徽标，默认关，参照 Skill 合约）、`删除`（默认**禁止**，红色警示"AI 默认禁止删除"，开启需二次确认） |
| 限频配置   | 每分钟读取上限（默认 60）、每分钟写入上限（默认 10）、单次批量条数上限（默认 20）、超限返回 429 + Retry-After 说明                                                            |
| 使用统计   | 今日请求数、读写比例、被拦截次数（mock 计数，可重置）                                                                                                      |
| MCP 后补 | 占位说明："MCP Server 规划中，将与 REST 共享同一鉴权与限频内核"                                                                                          |

> 对齐全 [API.md](API.md) 的能力清单（`/.well-known/capabilities`）与安全边界（AI 禁删、批量默认禁止），默认值与其一致。

### 4.4 日志

* 操作日志列表（倒序）：时间、操作、对象（标题/URL）、来源（工作台 / Agent / AI / 同步）、结果（成功/失败）。

* 类型过滤 chips：全部 / 新增 / 编辑 / 删除 / 整理 / 恢复 / 同步 / 备份 / Agent。

* 关键词搜索框（匹配标题/URL）。

* 分页：每页 20 条 + 上一页/下一页。

* 保留策略：条数上限（默认 5000）、保留天数（默认 30 天）可配；"清空日志"（确认）。

* **联动**：主视图产生的操作（单删/批量删除、状态变更、批量加标签、应用整理建议、恢复回收站、撤销）即时追加日志（模拟数据层持久于 localStorage）。

### 4.5 回收站

* 软删除书签列表：标题、删除时间、来源、倒计时（7 天自动永久清理）。

* 行操作：**恢复**（回到原状态/文件夹）、**彻底删除**（确认态）。

* 批量：勾选 → 批量恢复 / 批量彻底删除；**清空回收站**（需输入 `清空` 确认词）。

* 保留策略提示：7 天后自动永久清理（对齐 DATA\_MODEL 的 `deletedAt` 设计）。

* 空状态：插画 + "回收站暂无内容"。

* **联动**：主视图删除书签 → 进回收站（`isDeleted` 软删语义）；恢复后回到原位置。

### 4.6 Raindrop 同步（v0.2 新增）

| 分组     | 内容                                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| 连接与授权  | Access Token 输入（`type=password` 掩码，仅存 localStorage、界面不再明文回显）、**测试连接**按钮（模拟 700ms → 已连接 + 成功 Toast）、连接状态徽标（已连接 / 未连接） |
| 定时同步   | 启用开关（`sync.enabled`）+ 推送间隔预设 30s/60s/120s + 拉取间隔预设 5/15/30min（chips + 数值输入，自动保存）                                     |
| 手动同步   | **立即推送**（待处理数为 0 时禁用）、**立即拉取**、**全量拉取**（等价 API `force=true`）；**冲突策略** chips（本地优先 / Raindrop 优先 / 每次询问）；同步中禁用并显示状态灯   |
| 同步队列   | 待处理/失败/冲突/队列总数 统计卡 + 队列行（操作新增/更新/删除、推送/拉取方向、状态徽标、重试次数）；失败指数退避 1s→2s→4s 封顶 5min、断网保留不丢数据（对齐 [同步引擎细化.md](同步引擎细化.md)）   |
| API 限频 | 状态徽标（正常/退避中）+ 每分钟额度 / 剩余 / 重置倒计时 / 429 次数 统计卡 + 额度使用进度条；收到 429 读 Retry-After 暂停推送（对齐 [API.md](API.md) 5.x 限频语义）      |
| 同步日志   | 过滤 `bm.logs` 中 type=同步 的最近 8 条（时间/动作/对象/来源/结果），完整历史见「日志」分区                                                           |

> 模拟行为：点击同步按钮 → 复用 `runSync`（1.2s 模拟，第 3 次必然失败演示退避）→ 成功推进队首待处理项为已同步、剩余额度 −1；失败则队首标记失败、重试 +1、进入退避（remaining 归零、429 +1、reset 60s）。

## 5. 数据与状态设计（原型层）

### 5.1 types 扩展（`src/types/index.ts`）

```ts
export type SettingsTabKey = "status" | "raindrop" | "backup" | "agent" | "log" | "trash";

export type RaindropQueueOp = "create" | "update" | "delete";
export type RaindropQueueStatus = "pending" | "synced" | "failed" | "conflict";
export type RaindropConflictStrategy = "local" | "raindrop" | "ask";
export type RaindropRateStatus = "normal" | "backoff";

export interface RaindropQueueItem {
  id: number; op: RaindropQueueOp; direction: "push" | "pull";
  title: string; status: RaindropQueueStatus; retries: number;
}

export interface RaindropRateLimit {
  status: RaindropRateStatus; limit: number; remaining: number;
  resetInSeconds: number; retries429: number;
}

export interface RaindropConfig {
  token: string; connected: boolean; conflictStrategy: RaindropConflictStrategy;
  queue: RaindropQueueItem[]; rateLimit: RaindropRateLimit;
}

export interface AppSettings {
  sync: { enabled: boolean; pushSeconds: number; pullMinutes: number };
  raindrop: RaindropConfig;
  agent: {
    enabled: boolean; baseUrl: string; agentName: string;
    apiKey: string; capabilities: { query: boolean; save: boolean; edit: boolean; batch: boolean; delete: boolean };
    limits: { readPerMinute: number; writePerMinute: number; batchMax: number };
    stats: { todayRequests: number; writeCount: number; blockedCount: number };
  };
  backup: {
    schedule: { enabled: boolean; frequency: "manual" | "daily" | "weekly" };
    targets: BackupTarget[];
  };
  logs: { retentionCount: number; retentionDays: number };
  trash: { retentionDays: number };
}

export interface BackupTarget {
  id: string; type: "webdav" | "s3"; name: string; enabled: boolean;
  config: Record<string, string>; lastBackupAt?: string; lastSize?: string; lastResult?: "success" | "fail";
}

export interface LogEntry {
  id: number; at: string; type: LogType; action: string; object: string;
  source: "工作台" | "Agent" | "AI" | "同步"; result: "success" | "fail";
}

export interface TrashItem {
  id: number; title: string; url: string; source: Source;
  deletedAt: string; expiresAt: string; originalStatus: Status; originalFolder: string;
}
```

### 5.2 状态管理

## 7. 验收标准（原型层）

1. 侧栏底部含快捷操作组（主题/同步）与一行用户条（头像+用户名+设置胶囊按钮）；TopBar 无右侧操作按钮。
2. 点击"设置"打开居中模态，可 Esc/遮罩/× 关闭；五个分区可切换。
3. 备份区：CSV/ZIP 导出有进度与成功反馈；恢复有"合并/覆盖"选择与二次确认；云端目标可增删、连接测试与立即备份可演示；定时备份开关/频率可改。
4. Agent 区：Key 生成只显示一次、能力开关生效（删除默认禁、开启需确认）、限频数值可改并持久化；超限有 429 提示。
5. 日志区：列表可过滤/搜索/分页；主视图删除/整理/恢复操作实时出现在日志。
6. 回收站：删除书签后出现在回收站；恢复回原位置；彻底删除/清空有确认；倒计时展示。
7. 设置项刷新后保留（localStorage）。
8. v0.2：设置弹窗宽 960px、高度随内容自适应（≤90vh）；v0.2.1 起锁定为宽 60vw、高 80vh（切换分区窗口尺寸不变，内容超高在窗口内滚动）；「Raindrop 同步」分区含 Token 连接（测试连接/掩码仅存本地）、定时同步开关与间隔 chips、手动同步三按钮（立即推送/拉取/全量）、冲突策略、同步队列（待处理/失败/冲突 + 行状态）、API 限频（额度/剩余/重置/429/退避）、同步日志（type=同步 最近 8 条）。
9. `npm run typecheck` / `lint` / `build` 全绿；浏览器验证无控制台错误。
