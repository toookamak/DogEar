# DogEar · 落地拆解（执行项）

> 方向性，不定工期。按 P0 三优先，M1 前置阻塞后续，M2/M3 可并行。

## 队列与依赖
```
M1 存储抽象（前置一切）
  ↓
```

### M1：存储抽象
建立本地数据底座，为同步、关联、AI 提供统一存储接口，保证本地优先与 600 条基线的读写性能。

**核心交付：**
- 类型定义：`Bookmark{ id, raindropId, url, title, excerpt/aiSummary, folderId, tags[], status, showInNav, isPrivate, favicon, createdAt, updatedAt, syncStatus, source }` / `Folder{ id, raindropCollectionId, name, parentId, icon, sortOrder }` / `Tag / PageTab{ id, name, layout, sortOrder, filter } / DockerItem{ type, refId, order } / OperationLog{ id, at, actor, action, targetId, before/after } / SyncQueue{ id, bookmarkId, op, payload, attempts, nextRetryAt, status } / AiMemory{ signals, scope, updatedAt }`
- Storage 接口：`save / update / get / list / search`，含 `showInNav / syncStatus / updatedAt / isPrivate` 透传
- IndexedDB 适配器：`bookmarks / folders / sync_queue / operation_log` 四表，事务封装
- 索引：`url`（归一化唯一）、`folderId`、`tags`（多值）、`updatedAt`、`showInNav`、`syncStatus`
- 写入即写 `operation_log`（actor: user/sync/ai，含 before/after 用于回滚）
- 600 条假数据种子：覆盖多文件夹/多标签/多状态，用于分页/虚拟列表验证

**验收标准：**
- 工作台本地增删改能即时在列表中可见，无需网络
- `search/list` 在 600 条下按索引返回，体感流畅
- 每条变更均有 `operation_log` 记录，含前后快照
- 类型与接口与《数据模型草案》一致

### M2：同步引擎
建立本地与 Raindrop 之间的双向同步机制，保证数据一致性。

**核心交付：**
- 同步引擎核心：本地 → Raindrop 推送（Push），`sync_queue` 顺序消费，约 30s 轮询，按限速逐条推，成功回写 `raindropId` 与 `syncStatus=synced`
- 同步引擎核心：Raindrop → 本地拉取（Pull），`lastSyncAt` 增量，去重（url 归一化 + raindropId 映射），支持 5min/15min/手动三档 + 立即同步按钮
- 冲突检测与处理策略：同 id/url 双端交叉更新 → 标记 `conflict` 保留两端，不自动覆盖；`Last-Write-Wins` 仅作展示排序，实际以用户选择为准，支持字段级合并（标题/文件夹/标签/备注分字段对比）
- 冲突视图：常驻入口“发现 N 条冲突，去处理”，列表 + 左右对比（本地 | 远端：标题/文件夹/标签/备注/时间），操作 `用本地覆盖 / 用远端覆盖 / 手动合并 / 稍后处理`，支持单选/全选与批量“全部用本地/全部用远端”
- 限速与重试：429 读 `Retry-After`，指数退避 1s→5min 封顶，队列暂停，轻 Toast 提示“限频等待 N 秒”，断网保留队列联网续推
- 同步状态管理：`lastSyncAt`、`syncStatus`（pending/synced/conflict/failed）、`attempts/nextRetryAt`

**验收标准：**
- 本地修改能自动推送到 Raindrop（工作台改标题/文件夹/标签 → 30s 内 Raindrop 官方可见）
- Raindrop 端的修改能拉取到本地（官方插件新增 → 拉取后工作台可见）
- 冲突情况下不丢数据，两端皆保留，有明确的单/全选与字段级合并处理策略
- 操作日志与同步状态完整记录每次同步操作，含成功/失败/冲突

### M3：AI 输入（Skill）
打通 AI 收藏与检索闭环，Token 绑定即用，后续可调。

**核心交付：**
- 自描述：`GET /.well-known/capabilities` 返回 `{version:0.3, skills[]}`，含 `save_bookmark / search_bookmarks / update_bookmark / list_bookmarks / get_stats / batch_organize(experimental)`
- `POST /skill/save {url*, note?}`：抓取 title/favicon/excerpt → AI 建议 folder/tags/status → 写本地 → 进 sync_queue，回显 `{id, title, folder, tags, showInNav, aiSuggestion}` 便于 AI 告知用户
- `POST /skill/search {query*, filters?:{folder,tag,status,showInNav,dateRange}}`：标题/url/tags/备注模糊 + 自然语言召回（AI 记忆），本地索引，不做全文，分页 `limit/offset/hasMore`
- `POST /skill/list {status?, folder?, tag?, showInNav?, limit, offset}`：列表分页
- `POST /skill/stats`：`{total, byStatus, byFolder, recentWeek}`
- `POST /skill/update {id*, folder?, tags?, note?, status?}`：单条修改，禁删禁批量，写 operation_log，可回滚
- `batch_organize {ids[]}`（实验性）：仅返回 `{suggestions:[{id,folder,tags}]}`，需用户在工作台确认才生效
- 鉴权 `Bearer Token`（可吊销/轮换），限速 60/min，429 计入监测，错误 `{code, message}`

**验收标准：**
- 给 AI Base URL + Token 即可发现全部能力
- 丢链接给 AI 能完成收藏并在工作台可见（未读），AI 能回告知“已放到某文件夹/标签”
- 问 AI“导航页上那个设计收藏”能命中 `showInNav` 条目，模糊问“那个 xx 技术贴”能召回
- AI 单条修改可回滚，批量需工作台确认才生效，不直接写库

### M4：关联（工作台 ↔ 导航页）
建立显示控制与布局分离的关联机制，保证可开关与持久化。

**核心交付：**
- 工作台设置 `设置 > 导航页`：四选项 `全部显示 / 按规则-或 / 自定义勾选 / 全部隐藏`（与导航页开关互通）
- 按规则：多选文件夹/标签/状态，先做“或”逻辑（命中任一即 `showInNav=true`），后续扩展“与”组合，规则持久化
- 自定义：列表 + 搜索筛选 + 勾选，顶部 `已选 N / 共 600`，私密置灰需解锁才可勾，`showInNav` 写 bookmark 变更进 sync_queue（不进 Raindrop 额外字段）
- 导航页显隐：读 `showInNav` 过滤渲染，同域共享 IndexedDB（跨域备选 chrome.storage + 消息桥）
- 导航页编辑：固定分区（时间/搜索→页面标签→小组件区→文件夹图标区→书签图标区→Docker），页面标签横/竖排切换、拖拽排序、重命名、filter 规则持久化
- 文件夹：聚合图标（前4 favicon 拼合）+ 浮层展开 + 滚动
- Docker：增（拖拽/右键/设置）删（拖出/右键）排序持久化，不进 Raindrop，主网格删除时同步移除
- 编辑模式：空白双击/右键进入，拖拽跨页/跨区
- 开关持久化：`启用`开关无需二次确认，关闭后 `showInNav/page_tab/docker_items` 均保留，新标签页恢复浏览器默认，重开即还原

**验收标准：**
- 工作台按规则（或）/自定义搜索勾选后，导航页图标能即时显隐
- 导航页页面标签横/竖、拖拽排序、重命名、Docker 增删排序均持久化
- 导航页编辑不回写 Raindrop，仅改本地配置
- 关闭导航页后设置不丢失，重开即还原；私密内容仍需解锁

### M5：兜底与监测
保证可恢复、可观测与可备份。

**核心交付：**
- 软删除标记 + 删除同步：标记 `deletedAt` 保留 7 天可一键恢复，同步时传递删除态
- 操作日志：有限保留（默认 5000 条 / 30 天可改）+ 导出清理 / 直接清理 / 自动定期清理 / 循环覆盖 + 撤销条（工作台底部）
- 日志展示：`设置 > 日志` 列表 + 详情 before/after + 回滚入口
- 轻备份导出：HTML（浏览器可导入）/ CSV / Markdown 通用格式，按筛选（全部/文件夹/标签/状态/时间）导出
- 中/重备份方向：中（+ page_tab/docker/ai 配置）/ 重（全量快照含 log/queue），格式待技术定
- 速率监测：推送/拉取 条数/秒、平均时延、成功率、队列长度、429 次数，展示于 `设置 > 同步` 与日志

**验收标准：**
- 删除 7 天内可一键恢复，删除能同步到 Raindrop
- 日志按阈值自动循环覆盖，可导出/清理/回滚
- 轻备份 HTML/CSV/MD 第三方可读，按筛选导出正确
- 600 条批量推拉速率可在监测中查看，限频有 Toast

### M6：工作台/导航页核心闭环
完成整理与浏览的核心体验，保证 600 条基线性能。

**核心交付：**
- 两阶段整理：阶段一 保留/删除/待定（含全部保留/删除/待定）+ 统计 ✓/✕/?/未处理 + 撤销，待定用于需打开原网页后判断；右预览含标题/URL/“在浏览器中打开”新标签页返回 + AI 摘要/建议；阶段二仅保留条 AI 建议 folder/tags 采纳/修改/批量采纳/跳过，极少条可跳过阶段一
- 工作台联动：右侧“待处理”tab 底部“进入整理模式”入口，数据与状态联动
- 视图：网格（卡片封面+标签）/ 列表（紧凑行）切换 + 虚拟列表/分页（600 条）+ 排序
- 内联：悬浮卡片改 folder/tags/status，下拉选择器
- 批量：多选后工具栏 移动到文件夹 / 添加标签 / AI 批量回填预览（需确认后生效）/ 标记已读 / 删除确认
- 搜索：工作台 ⌘K 命令面板 + 导航页顶部居中下拉，标题/url/tags/备注模糊，相关度+时间排序，支持过滤
- 隐私：`isPrivate` 标记，导航页默认隐藏，查看需解锁（密码/系统认证方向性）
- 引导：首次引导 3 步（连 Raindrop/配 Token/选频率）可跳过，不配也能基础录入

**验收标准：**
- 12 条待处理能完成两阶段分拣到已整理，含批量与撤销
- 网格/列表/批量/AI 回填预览确认各闭环可演示，600 条下无卡顿
- 搜索下拉与私密解锁、首次引导可跳过均可演示
- 导航页开关与多视图切换符合 05.2 性能考核
