# DogEar · MVP 验收清单（草案 v0.1）

> **过期声明（2026-09-02）**：本清单仍对应旧 PRD v0.3.2 口径，**尚未按现行 PRD 回写**。验收冲突时以 [需求总纲 v1.0.7](../../wiki/DogEar_折耳书签_需求总纲_v1.0.7.md) 为准。
>
> 方向性草案，后续随技术方案调整。对应 PRD v0.3.2，容量基线 600 条。

## 1. 范围原则
- **P0 必过**：Raindrop 同步闭环、工作台↔导航页关联、AI 输入收藏，三项任一不通则 MVP 不算完成
- **可精简需确认**：非核心（小组件/统计/死链等）不得拖慢核心，必要时精简需与用户确认
- **技术待定**：本清单为功能验收，不锁定技术实现

## 2. 验收分组

### 2.1 Raindrop 同步（最高优先级）
| # | 验收项 | 通过标准（方向性） |
|---|---|---|
| S-1 | 本地为真源，写入即时响应 | 工作台/整理模式编辑后列表即时更新，不等待 Raindrop |
| S-2 | 编辑可推送回 Raindrop | 在工作台修改标题/文件夹/标签/备注/状态，定时推送后在 Raindrop 官方可见 |
| S-3 | 拉取增量 | 在 Raindrop 官方插件新增一条，定时拉取后在工作台可见 |
| S-4 | 冲突策略 | 本地与 Raindrop 同条冲突时默认本地为准，提供“用本地/用远端/手动合”入口 |
| S-5 | 限频与容错 | Raindrop 429/网络波动不阻塞本地操作，队列重试可在日志中查看 |
| S-6 | 容量基线 | 600 条量级下，推送/拉取体感可接受（具体阈值待技术方案定） |

### 2.2 工作台 ↔ 导航页关联
| # | 验收项 | 通过标准 |
|---|---|---|
| L-1 | 工作台控显 | 工作台可设“是否在导航页显示”，支持全部/按文件夹/按标签/自定义，多选 |
| L-2 | 导航页控布局 | 导航页决定图标/文件夹/小组件区布局、拖拽排序，改动不回写 Raindrop |
| L-3 | 一致性 | 工作台取消某条的“在导航页显示”后，导航页不再展示；反之新增后可展示 |
| L-4 | 开关 | 导航页可自由开关，关闭后工作台仍正常使用，且整体资源开销可感知降低 |
| L-5 | 隐私 | 标记私密的文件夹/标签在导航页默认隐藏，需解锁可见 |

### 2.3 AI 输入收藏（Skill）
| # | 验收项 | 通过标准 |
|---|---|---|
| A-1 | 自描述 | 仅提供 Base URL + Token，AI 访问 /.well-known/capabilities 可发现能力 |
| A-2 | 一键收藏 | AI 发 `url`（可选 `note`）即可完成收藏，自动抓取元数据、分类、标签、稍后读 |
| A-3 | 基础可用 | 不进“设置>AI”也能完成 A-2；设置>AI 仅为进阶（记忆预览/重置） |
| A-4 | 可检索 | 收藏后可在工作台搜索到，AI 记忆可辅助模糊检索（例如“那个xx技术贴”） |
| A-5 | 边界 | AI 默认不可删除/批量改/改文件夹结构，限速与日志可见 |

### 2.4 工作台核心
| # | 验收项 | 通过标准 |
|---|---|---|
| W-1 | 两阶段整理 | 阶段一 保留/删除/待定（含批量全部），阶段二 AI 建议采纳/修改，可跳过 |
| W-2 | 视图 | 网格/列表可切换，筛选与排序可用 |
| W-3 | 内联与批量 | 卡片悬浮可改文件夹/标签/状态；多选批量移动/打标签/AI回填（回填需确认） |
| W-4 | 预览 | 左列表右预览，含“在浏览器中打开”新标签页返回流程 |

### 2.5 导航页核心
| # | 验收项 | 通过标准 |
|---|---|---|
| N-1 | 固定分区 | 时间/搜索→页面标签→小组件区→文件夹图标区→书签图标区→Docker，从上到下 |
| N-2 | 页面标签 | 按内容维度命名，支持横/竖排切换、拖拽排序、重命名 |
| N-3 | 文件夹/图标 | 聚合图标，浮层展开，favicon 拼合/降级 |
| N-4 | Docker | 常驻、可拖拽增删排序、配置项（位置/大小/数量）生效 |
| N-5 | 搜索 | 顶部居中，下拉可打开，模糊匹配标题/域名 |

### 2.6 兜底与性能
| # | 验收项 | 通过标准 |
|---|---|---|
| E-1 | 软删除/日志 | 删除可恢复，日志有限保留（默认 5000/30天可改），支持导出/清理/循环覆盖 |
| E-2 | 轻备份 | 可导出 HTML/CSV/MD 通用格式，第三方可读 |
| E-3 | 引导 | 首次引导可跳过，不配置仍可基础录入 |
| E-4 | 性能 | 600 条基线下：导航页首屏/分页/Docker、工作台视图切换、整理模式切换、搜索下拉 体感流畅；数据读写（本地读写/同步/导入导出）可接受，有压力时可精简非核心（需确认） |

## 3. 非验收（Phase 2 后）
看板多维度、AI 批量深度、死链/重复/标签治理完整版、统计衍生、完整中/重备份、移动端
