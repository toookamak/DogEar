### 1.1 何时讨论升级（触发即停）

| 触发 | 典型要补的 | 对应里程碑 |
| --- | --- | --- |
| 要默认双向 Raindrop 同步，或自动冲突合并 | `conflict`；`sync_queue` 真消费与 429 退避 | M5 后期（本版不做） |
| 要引入端侧镜像缓存并让首屏读缓存 | Dexie schema（独立，不进本文件）；须重申保存成功仍以真源为准 | M5 后期（本版不做） |
| 要真正产出 SingleFile/monolith 单 HTML 并签名直传 | `archives.file_path` 有对象；禁止回执谎称已有文件 | M6 后期（本版不做） |
| 要每目标独立频率、备份恢复、ZIP 导入 | 另开备份目标表 | 备份设计稿，本版不做 |
| 导航规则求值并持久化展示集合 | 展示集合表或缓存 | M7 后期（本版只存规则） |
| 本表禁止项必须打破（URL 去重、主场景、多用户等） | 先改需求口径，再升结构表 | 无对应 Mx，须单独立项 |
| 实现中发现缺列/缺表，不补就做不完当前覆盖 | 先对照本文；仍缺则升级讨论，不私加 | 随时 |

工程约定（未升级前不变）：SQLite / D1 同一套 Drizzle；时间 `integer` 毫秒；布尔 0/1；枚举文本；JSON 文本；单实例无 `user_id`。落点 `packages/db`。不含 Dexie。已有表由 `initializeSqliteSchema` 幂等创建，不因本文升级改名。

## 13. `archive_jobs`

任务状态机。Skill、工作台快照按钮、设置页 Job 列表必须写**同一张表**，禁止 Snapshot 走 `archives`、Skill 走 `archive_jobs` 两套互不相通。无文件时不要填存储路径。失败不删书签。`type=reader` 由 API 拒绝，不入库。

对外 Job 状态用 `pending` \| `running` \| `succeeded` \| `failed` \| `cancelled`（与 API 结构表 v1.1 一致）。库内若仍有 `processing`/`completed`，读取时映射到 `running`/`succeeded`。

| 列 | 类型 | 空 | 默认 | 约束 |
| --- | --- | --- | --- | --- |
| `id` | text UUID | 否 | 生成 | PK |
| `bookmark_id` | text UUID | 否 | — | FK → bookmarks.id |
| `type` | text | 否 | `snapshot` | `snapshot` \| `metadata` |
| `source` | text | 否 | — | `agent` \| `browser` \| `server` \| `manual` |
| `status` | text | 否 | `pending` | `pending` \| `processing` \| `completed` \| `failed` \| `cancelled` |
| `error` | text | 是 | NULL | `fetch_failed` \| `parse_failed` \| `timeout` \| `quota` \| `unknown` |
| `retry_count` | integer | 否 | 0 | |
| `created_at` | integer ms | 否 | now | |
| `started_at` | integer ms | 是 | NULL | |
| `completed_at` | integer ms | 是 | NULL | |

Skill / 无 DOM：插入后保持 `pending`，接口语义 `queued_pending_browser`。

| `updated_at` | integer ms | 否 | now | |

`config` 形状（只存这些键）：

| channel | 键 |
| --- | --- |
| `raindrop` | `token` |
| `s3` | `endpoint` `region` `accessKeyId` `secretAccessKey` `bucket` |
| `webdav` | `url` `username` `password` |

本版用途：保存配置、测试连通、一次上传或下载冒烟。不做默认双向同步。

| 列 | 类型 | 空 | 默认 | 约束 |
| --- | --- | --- | --- | --- |

## 20. `backups`

三档备份运行记录。计划名 `backup_run` 不用，沿用本表。本版目标以 `local` 为主；`s3` / `webdav` 仅在通道已测通时可把同一份文件再传一次（连通冒烟），不做每目标独立频率、不做恢复、不做 ZIP 导入。

| 列 | 类型 | 空 | 默认 | 约束 |
| --- | --- | --- | --- | --- |
| `id` | text UUID | 否 | 生成 | PK |
| `tier` | text | 否 | — | `light` \| `medium` \| `full`（重档） |
| `target` | text | 否 | `local` | `local` \| `s3` \| `webdav` |
| `status` | text | 否 | `pending` | `pending` \| `running` \| `completed` \| `failed` |
| `file_path` | text | 是 | NULL | 完成后必须有，供下载 |
| `file_size` | integer | 是 | NULL | |
| `includes` | text JSON | 否 | — | 实际打进包的内容列表 |
| `error` | text | 是 | NULL | |
| `created_at` | integer ms | 否 | now | |
| `completed_at` | integer ms | 是 | NULL | |

三档内容（失败不回滚书签）：

| tier | 必须包含 | 本版可简化 |
| --- | --- | --- |
| `light` | 书签表：Netscape HTML 或 CSV 或 Markdown，至少一种可下载 | 可先出 CSV，但必须能下载 |
| `medium` | 轻档 + `settings`（无密钥）+ `channel_config`（密钥掩码或剔除） | 不得把 Token 打进备份 |
| `full` | 库文件或全表导出 + 已有快照文件（没有快照就省略并在 `includes` 注明）+ 中档配置 | 可先 `copy` SQLite；有快照再附上 |

中档不得再跑一遍轻档然后声称「含快照」。没有快照文件就不要写进 `includes`。
