# 数据库结构表

## 1. 当前覆盖与升级条件

写代码前先读本章。v1.0 只覆盖到这里；超出范围先停、先讨论、先升文档版本，再改 schema。

| 项 | 口径 |
| --- | --- |
| 当前覆盖 | **v1.0 = M3 + M4**。在 M2 的 `bookmarks` / `access_records` 上加列建表，支撑：工作台整理（四维、搜索、回收站、建议确认）、Agent 保存与审计、截网页只登记 Job。 |
| 本版有的表 | `bookmarks` `scenes` `bookmark_scenes` `folders` `tags` `bookmark_tags` `suggestions` `access_records` `operation_log` `settings` `archive_jobs` |
| 本版没有的表 | `sync_queue` `conflict` `archives` `archive_records` `backup_run` 导航规则 / Dexie 镜像 |
| 升级规则 | 下表任一触发即停。先讨论升级方案、升本文档版本，再写迁移。禁止边写代码边扩 schema。M3/M4 做完本身不构成升级。 |

### 1.1 何时讨论升级（触发即停）

| 触发 | 典型要补的 | 对应里程碑 |
| --- | --- | --- |
| 要接 Raindrop / S3 / WebDAV，或出现「未推送通道」而不只是真源 ACK | `sync_queue`、`conflict`；`raindrop_id` 开始有值；`sync_status` 语义是否拆开 | M5 |
| 要引入端侧镜像缓存 | Dexie schema（独立包，不进本 Drizzle 文件）；须重申保存成功仍以真源为准 | M5 |
| 要真正产出/下载快照文件，而不只是 Job 行 | `archives`、`archive_records`、`storage_location`；禁止继续空着撒谎 | M6 |
| 要跑三档备份并留历史 | `backup_run` | M6 |
| 导航页要按规则圈选并持久化 | 规则表 / 展示集合；Inbox 与私密默认不进导航 | M7 |
| 本表禁止项必须打破（URL 去重、主场景、多用户等） | 先改需求口径，再升结构表 | 无对应 Mx，须单独立项 |
| 实现中发现缺列/缺表，不补就做不完当前 Mx | 先对照设计稿；仍缺则升级讨论，不私加 | 随时 |

工程约定（未升级前不变）：SQLite / D1 同一套 Drizzle；时间 `integer` 毫秒；布尔 0/1；枚举文本；JSON 文本；单实例无 `user_id`。落点 `packages/db`，迁移接 `0001_m2_data_layer.sql`。不含 Dexie。

## 2. 硬约束

| 做 | 不做 |
| --- | --- |
| `bookmarks` 加列，主键不变 | 改已有 `id`、把 `access_records` 改名为 `access_log` |
| 创建当场 UUID，禁止 `tmp_` | URL 唯一约束（本版不去重） |
| 建议写 `suggestions`，确认后再写成员表 | `bookmark_scenes.source = ai_suggest` |
| 服务端写入成功 → `sync_status = synced` | 把 Raindrop 同步状态写入 `status` |
| Job 只登记，无 `storage_location` | `archives` / `sync_queue` / `conflict` / 导航规则表 |
| 软删用 `deleted_at` | 用 `status` 表示回收站或 Snapshot |

默认列表条件：`deleted_at IS NULL`。Inbox：`status = unread AND deleted_at IS NULL`。

## 9. `suggestions`

未确认建议。接受前禁止改 `bookmark_scenes` / `bookmark_tags` / `folder_id`。

| 列 | 类型 | 空 | 约束 |
| --- | --- | --- | --- |
| `id` | text UUID | 否 | PK |
| `bookmark_id` | text UUID | 否 | FK → bookmarks.id |
| `kind` | text | 否 | `scene` \| `folder` \| `tag` |
| `target_id` | text UUID | 是 | 已有对象 |
| `target_label` | text | 是 | 尚不存在的名字 |
| `confidence` | real | 是 | 0–1，只排序，不自动写入 |
| `rationale` | text | 是 | |
| `status` | text | 否 | `pending` \| `accepted` \| `deferred` \| `dismissed` |
| `created_at` | integer ms | 否 | |
| `resolved_at` | integer ms | 是 | |

接受：`kind=scene` → 插入 `bookmark_scenes`（`source=ai_accepted`，无 `target_id` 则先建场景）；`tag` 同理写 `bookmark_tags`；`folder` 写 `bookmarks.folder_id`（替换）。然后 `status=accepted`，记 `operation_log`。

| `target_type` | text | 否 | `bookmark` \| `scene` \| `folder` \| `tag` \| `suggestion` |
| `target_id` | text UUID | 否 | |

## 15. 查询条件（实现时按此过滤）

| 名称 | WHERE（另加 `deleted_at IS NULL`，回收站除外） |
| --- | --- |
| Inbox | `status = 'unread'` |
| 已确认 | `status = 'saved'` |
| 搁置 | `status = 'archived'` |
| 场景 | `bookmark_scenes.scene_id = ?`（含停用场景） |
| 文件夹 | `folder_id = ?` |
| 标签 | `bookmark_tags.tag_id = ?` |
| 标星 | `important = 1` |
| 未推送 | `sync_status = 'pending'` |
| 回收站 | `deleted_at IS NOT NULL`（不要再滤 deleted_at IS NULL） |

硬删书签（回收站清空）：同时删 `bookmark_scenes`、`bookmark_tags`、`suggestions`、`access_records`、未完成 `archive_jobs`。`operation_log` 可留。
