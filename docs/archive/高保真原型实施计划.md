# DogEar · 高保真前端原型实施计划

- **日期**：2026-08-31
- **版本**：v0.1
- **状态**：待实施确认
- **关联**：PRD v0.3.7 · 高保真原型规格 v0.1 · docs/README.md

**Goal**：在隔离目录 `dev/dogear-workbench` 以 Vite + React + TypeScript 重建 DogEar 工作台高保真原型，细化界面与交互状态，不接入正式工程。

**Architecture**：数据与界面分离 —— `types/ data/ hooks/ components/`；React 本地状态（useReducer）驱动筛选、选中、批量、建议与反馈；原生 CSS 令牌统一视觉。

**Tech Stack**：Vite · React · TypeScript · 原生 CSS · ESLint（仅 typecheck/lint/build，无其他工具链）。

---

## 0. 前置约定

- 全部命令在 `dev/dogear-workbench` 内执行；首次需 `npm install`。
- 验证命令：`npm run lint`、`npm run typecheck`、`npm run build`、浏览器人工验证。
- 提交规范：代码提交使用 `feat:` 前缀，关联原型规格；文档与代码分离提交。
- 浏览器预览：`npm run dev`（默认端口由 Vite 分配，以启动输出为准）。
- 原则：每个任务完成后运行 typecheck/build 并通过浏览器验证后再进入下一任务。

## 4. 风险与降级

- 首次 `npm install` 需要网络，若失败改用 `--registry` 镜像或提示用户手动安装。
- 看板拖拽用 pointer 事件自实现；若浏览器验证不稳定，降级为“列头按钮迁移 + 拖拽仅桌面演示”。
- Google Fonts 离线时回退系统字体，不影响布局验证。
