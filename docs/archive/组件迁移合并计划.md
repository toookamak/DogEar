* **日期**：2026-09-01
* **版本**：v0.1（草案）
* **关联**：[`docs/COMPONENTS-原型版.md`](COMPONENTS-原型版.md) v1.0（原型组件注册表，本计划的最终归属依据）、PRD v0.3.7
* **范围**：`dev/dogear-workbench/src/components/` 平铺结构 → 原子设计五层目录

> **适用**：本计划只针对**隔离原型**（`dev/dogear-workbench`）的组件迁移，与正式工程版 `COMPONENTS.md`（v1.1）无关。

## 1. 目标与原则

- **目标**：把当前平铺 `components/`（bookmarks / detail / feedback / layout / settings + settings/atoms + settings/sections）迁移为 `atoms / molecules / organisms / templates / pages` 五层目录，逐项落实注册表 v1.0 的 72 个登记项。
- **原则**：
  1. **视觉零变化**：迁移期间 CSS 类名与 DOM 结构尽量保持不变（纯拆文件 / 换 import），不顺手改样式
  2. **小步提交**：每个阶段独立提交，build + lint + dev 预览回归
  3. **先原子后分子再组织**：底层先稳定，上层才有依赖基础
  4. **就地声明式拆分**：内联元素（如 `.status-dot`、`.tag-pill`）先抽原子，父组件改为引用，同时把对应 CSS 段迁到组件的局部样式或标注归属

## 4. 阶段计划

> 每阶段：独立分支 → 完成 → build + lint → dev 预览回归（视觉 diff 对比迁移前后截图）→ 提交并推进 COMPONENTS.md / 本计划落地状态。

**Phase 0 · 基线（前置）**
- 建立 tokens 语义核对：抽出原子的颜色/圆角/字号先对齐 `tokens.css`，避免拆分时带出魔法值
- 产出：`styles/` 无改动或仅加注释

**Phase 1 · 原子层**
- 新建 `components/atoms/`，先落地零争议原语：Icon、StatusDot、Monogram、CountBadge、TagPill、StatusPill、SourceBadge、Chip、Divider、Backdrop、SkeletonBlock、SectionLabel、Avatar、Brand
- 父组件（Sidebar / BookmarkCard / TopBar / StatusBar / Skeleton）改为引用，CSS 段随迁（.tag-pill 等）
- 验收：侧栏与卡片视觉不变，`npm run build` ✅，无未用 CSS 告警

**Phase 2 · 按钮与表单原子**
- IconButton、SegButton、MiniButton、PrimaryButton、SecondaryButton、FilterChip、ViewButton、TextInput、SortSelect、Kbd
- 统一 `.icon-btn` 8 处副本为单一组件（注意 menu/sync/select 尺寸差异用 props）
- 验收：工具栏、批量条、详情、设置操作区行为不变

**Phase 3 · 设置原子并入**
- settings/atoms（Switch、ConfigField→FormField、KeyField、StatCard）移入 atoms，命名对齐注册表
- 验收：设置弹窗全分区可用

**Phase 4 · 分子层**
- 按注册表 22 个分子逐项落地：先卡片系（CardCover/CardPreview/SelectButton/CardTagsRow/DomainLink），再工具栏系，再侧栏系，最后 ToastItem/PageHead 等
- BookmarkCard / WorkspaceToolbar / Sidebar / DetailPanel / TopBar / StatusBar 改为引用分子
- 验收：三视图卡片渲染一致；侧栏交互（主题菜单全宽弹出、标签筛选）不变

**Phase 5 · 组织与模板**
- BookmarkGrid/List/Board、SelectionToolbar、DetailPanel、EmptyState、SkeletonScreen、ToastRegion、SettingsModal、SettingsSection 归入 organisms
- AppShell → `AppShellLayout`；设置弹窗骨架 → `SettingsLayout`
- App.tsx → `WorkbenchPage`（pages/），main.tsx 引用调整

**Phase 6 · 清理与收尾**
- 删除旧平铺目录残留，全仓 grep 旧 import 清零
- 同步 COMPONENTS.md 落地状态、本计划勾选、`docs/README.md` 版本推进
- 全量回归：build + lint + 三视图 + 设置六分区 + 深浅主题 + 批量操作 + 拖拽看板

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 拆组件时 CSS 选择器依赖父级（如 `.card-preview source-*` 由卡片级变量着色） | 原子/分子自带局部 class + props 传来源色，不依赖父级变量 |
| `.icon-btn` 多处副本尺寸/圆角不一致 | Phase 2 先统一 tokens 再抽组件 |
| 侧栏标签与卡片标签样式漂移 | 以注册表 TagPill 为唯一实现，迁移后回归比对截图 |
| 大文件单次改动过大（Sidebar / BookmarkCard / AppShell） | 每个文件独立拆分 commit；先抽中间分子再重组 |
| 模态/遮罩点击区域改变 | Backdrop 统一后逐处手测（侧栏、详情、设置） |
