## 1. 项目概述

### 1.1 项目背景

个人用户在研究、工作与日常浏览中持续积累网页链接，并需要在较长周期内完成保存、整理与再次访问。

| 现有手段 | 能力 | 缺口 |
| --- | --- | --- |
| 浏览器收藏夹、第三方书签服务 | 持久化 URL | 保存入口有限；保存常与即时分类绑定；入库后缺少稳定的检索与再发现 |
| 阅读器、笔记工具 | 保存正文 | 对象由链接转为内容，采集与维护成本上升，偏离以书签为主体的使用方式 |

DogEar（折耳书签）面向上述问题，建设以 **Bookmark** 为基本对象的个人网页信息收集与管理系统。网页快照等归档能力用于提高已保存链接的长期可用性，不改变系统作为书签工具的定位。

### 1.2 核心目标

| # | 目标 | 说明 |
| --- | --- | --- |
| 1 | **降低保存成本** | 保存与分类、内容保全在流程上解耦 |
| 2 | **按情境组织** | 支持按使用情境组织书签，降低对固定文件夹与标签体系的依赖 |
| 3 | **可检索、可再发现** | 已保存书签保持可回访，避免入库后不可达 |
| 4 | **按需内容保全** | 在需要时保存网页内容，以应对原页面失效或变更 |

### 1.3 使用场景

| 项 | 说明 |
| --- | --- |
| **使用者** | 有持续网页收集与长期回访需求的个人用户。不面向多人协作 |
| **运行环境** | 以 Web 工作台与 Skill API 为主要交互界面；浏览器扩展为可选入口。部署形态为云端服务或容器自托管 |

**典型场景**

1. 经工作台提交 URL，系统生成书签记录。
2. 经 AI 助手调用 Skill API 保存链接。
3. 在工作台按情境、状态或关键词检索并修订书签。
4. 经导航页访问已纳入展示范围的书签。
5. 按需导入外部书签库，或导出链接级存档。

### 1.4 非目标

本系统不作为笔记工具或阅读器建设，不提供重型文本编辑。

| 类别 | 不纳入本阶段 |
| --- | --- |
| 内容消费 | 清洗阅读版（Reader）、正文圈选、高亮 |
| 终端形态 | 移动端应用、系统分享扩展、URL Scheme |
| 产品规则 | URL 去重 |
| 外部依赖 | 以外部书签服务作为运行前提、登录条件或多端主存储 |
| 预支实现 | Scene 层级、复杂规则引擎、多端 CRDT |

| **规则层 Rule** | 导航圈选、AI 建议、AERR（仅内部） | R3、O6 | `apps/server` · `packages/shared` |
| **数据层 Data** | 真源、缓存、内容对象、可选通道 | D1–D5 | `packages/db` · 通道适配器 |

**依赖方向**

```text
Entry / UI  →  Core  →  Data
                 ↑
               Rule
Utils 被各层使用；Data / Server 不得反向依赖 UI
```

### 3.4 核心功能详细设计

#### 3.4.1 Capture：创建 Link

| 项 | 说明 |
| --- | --- |
| **设计模式** | 同步写入结构化记录，异步补全 Metadata / 可选 Snapshot |
| **设计原则** | 保存路径最短。整理、抓取或外部通道失败，均不得回滚 Bookmark |
| **扩展性** | 可增加入口；创建语义不变 |
| **关键模块** | `saveBookmark`；入口适配；`ArchiveJob(metadata)` |
| **输入** | `url`（必填）；`note`、`intent`、`snapshot`（默认 `false`）可选 |
| **输出** | Bookmark；默认待处理；可选建议（默认不写入结构） |
| **流程** | 校验 URL → 写入真源 → 返回 → 入队 Metadata → 仅在显式勾选时入队 Snapshot |

#### 3.4.2 Organize：四维组织与工作台

| 项 | 说明 |
| --- | --- |
| **设计模式** | Scene / Status / Folder / Tag 独立组合。工作台单壳，Scene 仅切换上下文 |
| **设计原则** | 保存不强制 Scene；Inbox 不强制转出；AERR 不向用户展示 |
| **扩展性** | Scene 为可配置数据，禁止固定枚举 |
| **关键模块** | Scene 与成员表；Status 状态机；Folder / Tag；列表查询 |
| **输入** | 筛选条件；单条或批量补丁 |
| **输出** | 更新后的 Bookmark；操作日志；可撤销 |
| **流程** | 读取 → 校验补丁（AI 路径走建议态）→ 事务写入 → 刷新列表 |

> 成员表、置信度等细部见 [`docs/module/Scene-AI与待设计细部.md`](module/Scene-AI与待设计细部.md)。

#### 3.4.3 Skill API

| 项 | 说明 |
| --- | --- |
| **设计模式** | 自描述能力清单 + Bearer Token；不绑定特定 AI 平台 |
| **设计原则** | `save` 须回显；结构字段默认不自动写入；`batch_organize` 标 experimental，确认后生效 |
| **扩展性** | 增补 capabilities 即可被再发现；契约变更提升 version |
| **关键模块** | `GET /.well-known/capabilities`；`POST /skill/*`；限速与用量 |
| **输入 / 输出** | 见 [§7.2](#72-外部接口) |
| **流程** | 鉴权 → 限速 → 执行 → 写操作记日志 → 统一错误体 |

#### 3.4.4 Snapshot / Archive Job

| 项 | 说明 |
| --- | --- |
| **设计模式** | Job 与 Bookmark 解耦；来源可降级（server / browser / agent / manual） |
| **设计原则** | 内容保全不等于保存成功 |
| **扩展性** | `type` 预留 `reader`，本阶段不实现 |
| **关键模块** | Job 队列；抓取执行器；内容存储适配器；Archive Record |
| **输入** | `bookmark_id` + `type=snapshot` |
| **输出** | 内容对象 + Record（parser / source / storage_location） |
| **流程** | 创建 Job → 执行 → 写入内容层 → 回写 Record。失败可重试，Bookmark 保持有效 |

#### 3.4.5 导航圈选

| 项 | 说明 |
| --- | --- |
| **设计模式** | 工作台决定是否展示，导航页决定布局。规则运算先做 **或** |
| **设计原则** | 不以逐条点选为唯一方式。关闭导航不得丢失页面标签与 Docker 配置 |
| **扩展性** | 长期可拆 `Bookmark → Navigation Item → Navigation Page`；本阶段不提前建表 |
| **关键模块** | 规则持久化；展示集合；只读查询 |
| **输入** | 全部 / 按规则（或） / 自定义搜索勾选 / 隐藏 |
| **输出** | 可渲染集合。默认排除 Inbox、私密及被排除项，除非规则明确纳入 |
| **流程** | 保存规则 → 求值 → 导航页读取 → 打开时写访问记录 |

#### 3.4.6 可选数据通道

| 项 | 说明 |
| --- | --- |
| **设计模式** | 通道适配器。零通道时产品完整可用 |
| **设计原则** | Raindrop 为输入源和 / 或导出存档，不是默认定时双向同步，不做双端 CRDT |
| **扩展性** | S3、WebDAV 等同为选项，可多选 |
| **关键模块** | 导入任务；导出任务；附录 C 白名单投影 |
| **不映射** | Scene、Status、圈选、AI 建议 |
| **输入 / 输出** | 用户启用的方向；导入进应用或导出 Link 级存档。回收站默认不导出 |
| **流程** | 见 [§5.3](#53-通道流程选用时) |

### 3.5 功能边界与限制

| 场景 | 处理 | 依据 |
| --- | --- | --- |
| 外部通道未配置或中断 | 应用内保存与整理照常；恢复后执行已配置的导出 | PRD §5.2.3 |
| 应用不可达 | 本阶段不承诺保存 | 保存前提为应用可达 |
| Snapshot 失败 | Bookmark 成立；Job 可重试 | 保存与保全解耦 |
| AI 低把握 | 不写入 Scene | PRD §2.0.2 / §4.2.7 |
| AI 删除、改文件夹结构、默认批量 | 拒绝 | PRD §6.1 |
| 与外部记录冲突 | 保留两端，由用户选择；不阻塞本地写入 | PRD §6.2 |
| 超过 600 条 | 非核心能力可降级；保存与搜索不得失败 | 600 为性能基线，非条数上限 |
| Reader、去重、移动端 | 不实现 | 愿景或明确非核心 |

### 3.6 功能迭代路线

## 5. 核心流程设计

### 5.1 主流程（Capture）

```text
开始
  │
  ▼
入口：工作台 / Skill / 扩展（可选）
  │
  ▼
校验：应用可达；URL 合法
  │
  ▼
写入 Bookmark（Link，默认待处理）
  │
  ▼
返回结果（Skill 须回显建议；结构默认不落库）
  │
  ├──► 异步 Metadata Job
  │
  └──► 仅当显式勾选：Snapshot Job（失败不回滚）
  │
  ▼
可选：高把握时给出 Scene 建议（低把握不写）
  │
  ▼
结束（整理不在本路径上）
```

### 5.2 关键逻辑

#### 保存与保全解耦

| 项 | 说明 |
| --- | --- |
| **输入** | 创建 Bookmark 的请求 |
| **输出** | 必有 Link；内容对象可缺省 |
| **原则** | Link 写入成功即完成保存；Snapshot 为独立 Job |
| **步骤** | 同步写结构化记录 → 入队异步任务 → 调用方不等待抓取完成 |
| **复杂度** | 创建为常数时间写入；抓取成本隔离在 Job |

#### 导航圈选（规则 · 或）

| 项 | 说明 |
| --- | --- |
| **输入** | 全部 / 条件或 / 自定义勾选 / 隐藏 |
| **输出** | 展示集合 |
| **原则** | 工作台计算是否纳入导航；导航页不解释业务规则 |
| **步骤** | 持久化规则 → 物化或查询时求值 → 私密内容须解锁 |
| **规模** | 本阶段按 600 条基线全量求值。超基线后的增量物化为暂定 |

#### 外部书签字段映射

| 项 | 说明 |
| --- | --- |
| **输入** | 应用内 Bookmark |
| **输出** | 附录 C.1 同构字段。不含 Scene、Status、圈选、AI |
| **原则** | 导出为存档，不迁移使用情境；导入不生成 Scene |
| **步骤** | 按白名单投影；回收站默认跳过 |
| **限频** | 退避重试；不阻塞应用内写入 |

#### AI 建议分流

| 项 | 说明 |
| --- | --- |
| **输入** | URL、标题、可选 intent、已有维度 |
| **输出** | 至多一个 Scene 建议、少量 Tag / Folder、一句说明 |
| **原则** | 建议先行；默认不自动执行；可撤销 |
| **步骤** | 浅理解 → 低把握则空建议 → 用户采纳后写结构并记日志 |
| **约束** | 不得延长保存返回路径；建议可异步 |

### 5.3 通道流程（选用时）

```text
首次使用
  → 数据管理选择（可跳过）
  → 开始保存

启用为输入源
  → 首次导入：进入 Inbox，或保持原路径（梳理页可跳过）
  → 此后该源新到的零散记录 → Inbox

启用为导出方向
  → 写出 Link 级存档
  → 不写出 Scene / Inbox
  → 不以删除标签双向推送为核心模型
```

任务调度、增量策略见 [§11](#11-待确认--待决策事项)，本文仅锁定产品方向。

### 6.1 配置结构（方向示意）

应用配置与通道开关纳入中档备份。存储形态待定，语义如下。

```json
{
  "app_name": "DogEar",
  "version": "待定",
  "data_management": {
    "raindrop": { "enabled": false, "as_input": false, "as_export": false },
    "s3": { "enabled": false },
    "webdav": { "enabled": false }
  },
  "capture": {
    "default_status": "unread",
    "agent_auto_snapshot": false
  },
  "navigation": {
    "selection": { "mode": "all | rule_or | custom | hidden" },
    "require_auth": true
  },
  "retention": {
    "trash_days": 7,
    "operation_log_max": 5000,
    "operation_log_days": 30
  }
}
```

关闭导航或变更圈选规则时，**不得删除** `page_tab`、`docker_items`。

### 6.2 核心数据结构

```text
Bookmark
├── id                          应用主键；未导出前可为临时 id
├── url
├── Metadata                    自动抓取，可修正
├── tags[] / folder / note / important
├── scenes[]                    多对多，可空
├── status                      unread | saved | archived
├── source                      page | agent | extension
├── archives[]
├── visit records               本阶段先落库
└── timestamps

Scene
├── id / name / description / appearance?
├── sort_order / enabled
└── aerr_profile                系统内部，不展示

ArchiveJob
├── id / bookmark_id
├── type                        metadata | snapshot | reader（预留）
└── source / status / error / result

ArchiveRecord
└── parser / parser_version / source / storage_location

NavSelection / PageTab / DockerItem
└── 相对通道的本地配置；关闭导航不删除

OperationLog / Trash
```

| 关系 | 说明 |
| --- | --- |
| Bookmark ↔ Scene | 多对多 |
| Bookmark → Folder | 通常单属 |
| Scene 与 Tag | 不得以 Tag 前缀模拟 Scene |

### 6.3 数据存储格式

| 类别 | 形态 | 说明 |
| --- | --- | --- |
| **用户配置** | 应用库中的设置对象 | 引擎待定；纳入中档备份 |
| **操作日志** | 结构化记录 | 默认 5000 条 / 30 天，可配置；可清理、导出、循环覆盖 |
| **业务数据** | Bookmark / Scene / Folder / Tag / Job / Record | 应用真源 |
| **缓存** | 端侧缓存（IndexedDB 为候选） | 首屏与离线读取；不得取代真源 |
| **内容** | Snapshot 资源 | 与结构化数据分离；不进入外部书签存档 |
| **其它** | 访问记录（核心，字段待定）；组织记忆（近期） | 本阶段可不建记忆表 |

### 6.4 数据生命周期

| 数据 | 创建 | 更新 | 删除 | 持久化 |
| --- | --- | --- | --- | --- |
| Bookmark | Capture 成功时 | 用户修订、采纳建议、Metadata 回填 | 软删除，默认 7 天 | 应用真源 |
| Scene | 预置四场景或用户新建 | 改名、停用、合并（合并细部待设计） | 停用优先于物理删除 | 应用真源；不进入外部存档 |
| Metadata | 异步 Job | 用户修正优先 | 随 Bookmark | 同构字段可导出；本地扩展仅本地 |
| Snapshot | 勾选或事后触发 | 重抓、上传替换 | 可删内容，不删 Bookmark | 内容存储层 |
| 访问记录 | 打开原链接（及日后打开 Snapshot） | 追加 | 策略待定 | 应用真源 |
| 导出存档 | 启用导出后 | 按通道任务 | 不删除应用数据 | 外部服务 |
| 备份包 | 用户触发 | 生成新文件 | 保留策略待定 | 轻 HTML/CSV/MD；中含配置；重含 Snapshot |

### 7.2 外部接口

工作台 REST 与 Skill **共用 Core**。鉴权可为会话或 Token，业务语义不得分叉。

#### `GET /.well-known/capabilities`

| 项 | 说明 |
| --- | --- |
| **方法** | GET |
| **参数** | 无 |
| **响应** | `{ version, skills[] }` |
| **技能** | `save_bookmark`、`search_bookmarks`、`update_bookmark`、`list_bookmarks`、`get_stats`、`trigger_archive`、`suggest_scene`；`batch_organize` 标 `experimental` |
| **错误** | `401` 无令牌 |
| **认证** | 清单可发现；调用技能须 Bearer |

#### `POST /skill/save`（路径暂定）

| 项 | 说明 |
| --- | --- |
| **参数** | `url*`；`note?`、`intent?`、`snapshot?`（默认 `false`） |
| **响应** | Bookmark 摘要 + `aiSuggestion`（结构默认未写入） |

| **约束** | 截取失败不回滚；禁止删除 |

#### 其他 Skill

| 技能 | 输入 | 说明 |
| --- | --- | --- |

| `suggest_scene` | id 或批量 id | 仅建议，确认后生效 |

## 8. 异常与边界处理

| 场景 | 触发 | 处理 | 反馈 |
| --- | --- | --- | --- |
| 应用不可达 | 工作台或 Skill 无法连接已部署服务 | 不写入 | 明确失败 |
| 外部通道中断 | Raindrop / S3 / WebDAV 不可用 | 应用内照常写入；通道任务挂起 | 限频提示 |
| Snapshot 失败 | 抓取超时或站点限制 | Job 失败；Link 保留 | 可重试 |
| Metadata 失败 | 无法抓取标题等 | Bookmark 有效；可重试 | 列表以 URL 占位 |
| 限频 | 外部 API 或 Skill 超限 | 指数退避；队列保留 | 提示等待时长；不阻塞本地 |
| AI 越权 | 删除、默认批量、改结构 | 拒绝并记日志 | 不执行 |
| 冲突 | 导入 / 导出与本地交叉修改 | 保留两端，由用户选择 | 提供冲突入口；不自动覆盖 |
| 私密内容 | 导航未解锁 | 不展示 | 解锁后可见 |
| 超基线 | 规模显著超过 600 条 | 非核心降级 | 保存与搜索仍可用 |

### 8.1 数据校验

- URL 必填且可解析；创建不要求 Metadata 完整。
- Scene / Folder / Tag / Status 补丁须指向存在且未停用的对象。
- Skill 写操作限于白名单字段；未知字段忽略或返回 `400`（须在合约中选定）。
- 导出仅投影附录 C 白名单。

### 8.2 错误处理原则

1. 保存是否成功，仅以应用真源是否落下 Link 为准。
2. 异步失败可重试，不得改写已成功的 Bookmark。
3. 用户操作可撤销；AI 写操作须可追溯、可批量撤销。
4. 通道错误不得表现为保存失败。

### 8.3 日志策略

| 项 | 说明 |
| --- | --- |
| **级别** | 写操作全量（user / sync / ai）；读操作抽样或仅用量（待定） |
| **格式** | `actor, action, target, before, after, at` |
| **位置** | 应用数据库，与业务同真源 |
| **保留** | 默认 5000 条 / 30 天，可配置；支持清理、导出、循环覆盖 |
| **观测** | 条数/秒、时延、成功率、队列长度、429（见 `AGENTS.md`） |
