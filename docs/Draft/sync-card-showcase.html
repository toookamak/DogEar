比例系统说明（组件落地时直接沿用）

  • 单一基准：灯珠直径 L。灯距 / 灯罩内衬 / 卡片内衬 / 列距 / 行距 / 字号 / 光晕半径，全部 = L 的倍率（calc() 派生）。改 L 即整体缩放，比例恒成立。
  • 日期格式统一：所有展示位一律 MM-DD HH:mm（月-日 时:分，无年份），最长形态为 11 个半宽字符 —— 值位 11ch 锁宽，短内容留白落在值位内；队列按 999（3 位）锁宽。任何状态下卡片 / 胶囊边界恒定。
  • 方案 A：数字放大至 1.5L / 600 / 状态色 置卡上半、贴齐灯箱；日期行 0.8L 右对齐贴卡右下（标签 faint、值 muted）。主次对角、无混排。≈ 76px 高 × ≈ 152px 宽。
  • 方案 D：默认仅胶囊灯组（无文字）；悬停或点击向右滑出信息 —— 队列数 1.25L / 600（3 位锁宽）贴灯、日期 0.6L faint 由 margin-left:auto 推至最右、两段之间留白。点击可 .open 钉住展开。
  • 字号与灯珠同源：方案 A 主数字 1.5L、单位 0.72L；D 主数字 1.25L、单位 0.62L；行高收敛 1.05–1.2，无基线错位。
  • 尺寸：方案 A ≈ 76px 高 × ≈152px 宽；方案 D 折叠胶囊 ≈ 29px 高 × ≈68px 宽，展开后信息区定宽 160px（L=15px）。密度档位只调 --L，无需重排。
