设计说明与改动对照

按 AGENTS.md「界面怎么做 / 先稿后码」：本稿只说清每一屏有哪些块、主操作、空状态，并逐条对照现状。确认前不写界面代码、不改全局样式、不改 DESIGN.md。

为什么动的是信息架构，不是配色

你的两条反馈——「功能庞大但不想用」「Raindrop 流程不清晰」——都不是视觉问题。配色沿用现有 Notion 风不变，本稿改的是三件事：①主入口从「浏览收藏」换成「哪里乱」；②把批量操作提到一屏之内；③把「推没推」变成常驻可查状态而非设置页里的一个下拉。

维度现状本稿为什么
默认落点Inbox（待处理，Status 的一个值）没归类的（派生视图）Status 隐藏后，派生视图接管「待整理」，且算出来的比存出来的更准
侧栏首组Inbox / 书签 / 场景哪里乱（4 个派生视图）打开就要回答「我该从哪儿下手」，而不是「有哪些维度」
组织维度场景 / 文件夹 / 标签 / 状态 四维平级收藏夹 + 标签 为主；场景降为「本地场景（不回写）」按拍板决策二；四维里两维是 Raindrop 已有的，一维砍掉，一维降级
主视图看板 / 网格 / 表格 / 标签 四视图平级列表为默认，网格为可选批量整理要密度和多选，看板对这个任务反而更差
批量操作顶部工具栏一行，选项多、易漏选中即浮出独立操作条「一批 200 条 10 秒改完」是本产品唯一不可替代的价值
同步语义顶栏胶囊「待同步 N」，入口在设置页「12 条待回写」+ 工具栏「同步一次」从「同步」改成「回写」，直接回答「我改的到了没有」
首次使用设置 → 输入源/导出 → 添加通道 → 手填 Token第一屏 OAuth 一键，授权后立刻看存量整个产品的啊哈时刻在「看到我自己的东西」，不在「保存按钮」
搜索⌘K 只索引已加载的那一页3,412 条全量端侧索引 + 行内直接改你原话「需要他完整好查」；现状确实搜不全
AI 建议 / Snapshot各占一处处入口隐藏（开关保留）AI 目前是空占位，留着只增加「看起来很复杂」
S3 / WebDAV设置页三个 tab 平级保留，位置降权按你的要求不删，后续会恢复

逐屏：块 / 主操作 / 空状态

屏 1 · 首次连接

块：品牌标记 · 标题「连上你的 Raindrop」 · 一句价值说明 · OAuth 主按钮 · 「或」分隔 · 手填 Token 次入口 · 「不连接也能用」免责说明 ／ 右侧并排展示拉取进度态（连接→读收藏夹标签→拉书签→建索引 四步）。

主操作：用 Raindrop 账号连接（全宽、38px、橙底）。全屏唯一主按钮。

空状态：未连接时点「同步一次」→ 回落到屏 1 授权卡，并提示「先连上才能拉取远端收藏」。拉取失败 → 进度卡第三步转红字「连接中断，已入库 2,116 条，可重试」（不允许只弹 toast 后消失）。

屏 2 · 整理台（默认态）

块：顶栏（视图名 + 计数 · 常驻搜索 · 回写胶囊） · 侧栏（「哪里乱」4 项 + 收藏夹白卡 + 标签白卡 + 本地场景区 + 账户菜单） · 工具栏（列表/网格 · 筛选 · 排序 · 全选本页 · 同步一次） · 列表（选择框 · 标题/来源 · 收藏夹 · 标签 · 收藏 · 日期） · 状态栏。

主操作：同步一次（工具栏最右实底）。其余全为 ghost。

关键设计：「没归类的」这个视图里，收藏夹与标签两列大面积留空并显示细点 + 「未归类／无标签」——乱不乱不靠数字说，靠你一眼扫到一片空。

空状态：某派生视图清零后 → 虚线框 + 「这个视图已经清空了」+ 次级说明「这是好事：说明没有漏网的收藏」+ 一个「去看全部收藏」ghost 按钮。清零要庆祝，不要显示成故障。

屏 3 · 批量整理（选中态）

块：与屏 2 同构，追加底部居中浮起的批量操作条（已选 N 条 · 移入收藏夹 · 加标签 · 加到本地场景 · 应用到 N 条 · 取消）。选中行 = 左 2px 橙条 + 内描边橙环（沿用 DESIGN.md §4 状态四件套，不新造样式）。

主操作：应用到 N 条（条内唯一实底橙）。

空状态：批量条不出现即表示无选中——不用额外的空态占位。跨页选择时状态栏持续显示「本页 4 / 已选 214」。

要你拍板的细节：「加标签」是追加还是替换？替换风险高（可能抹掉别人的归类），我倾向默认追加 + 单独提供「整理标签」入口。

屏 4 · 全量搜索

块：大搜索框（带高亮） · 命中统计条（条数 + 耗时 + 覆盖字段） · 结果列表 · 侧栏（搜索范围 + 收窄条件） · 状态栏（索引条数）。

主操作：结果行内直接改收藏夹／加标签（hover 显形）。这是本屏唯一新增能力，也是「搜到就能理」的落点。

空状态：无命中 → 「没找到 houdini」+ 三条建议（换个词 / 只搜标题 / 看看近半年新增）+ 「按标签 #Houdini 浏览」这个出口——搜索失败时给下一步，别只说没有。

刻意没做的（以及原因）

  • 没做深色：本期只出浅色；深色结构同形，确认后另出一版，不在这稿里猜。
  • 没画详情面板：字段要按「Folder / Tag / Scene / 标题 / 备注」收敛，涉及取舍，等主稿定了一起出。
  • 没画设置页：本轮只定主流程。S3 / WebDAV 保留后的设置页形态留到批次 4。
  • 没动导航页：它在新定位里是「找」的旧解法，等搜索定稿后再决定去留。
  • 没动 DESIGN.md：本稿全部照它实现，没发现需要改视觉源的地方。若确认后有偏离，会单独提请你拍板。
