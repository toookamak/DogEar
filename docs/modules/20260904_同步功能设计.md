# 同步功能设计

## 1. 设计目标

Raindrop 作为可选第三方通道，提供 Token 认证的自动/手动同步能力。不是备份，而是**双向的通道同步**，涉及冲突处理、导入梳理等逻辑。

## 2. 配置项

| 配置项 | 说明 |
| --- | --- |
| Token | Raindrop API Token（测试令牌或 OAuth），输入框显示前3后3，中间用* |
| 自动同步 | 开关，开启后按设定的时间间隔自动同步 |
| 同步间隔 | 每15分钟 / 每30分钟 / 每小时 / 每6小时 / 每天 |
| 手动同步 | 按钮，点击立即执行一次同步 |
| 最近同步 | 显示最近一次同步时间和状态 |

## 3. 同步行为

- **同步方向**：双向（Raindrop → DogEar 真源；DogEar 真源 → Raindrop）
- **冲突处理**：本地优先（保留本地版本，Raindrop 版本作为副本保存）
- **导入新书签**：默认进入 Inbox，可跳过导入梳理页
- **不同步**：Scene、Status、回收站内容不写回 Raindrop
- **同步记录**：每次同步记录日志，显示最近同步时间和状态

## 4. 设置页面布局（示意）

```
┌─ Raindrop 同步 ───────────────────────────────┐
│  Token: abc***xyz                       [保存] │
│  状态: 已连接 ✅                                │
│  ──────────────────────────────────────────── │
│  自动同步 [开]  间隔 [每30分钟 ▼]              │
│  最近同步: 2026-09-04 11:00 ✅                 │
│  [立即同步]                                     │
└─────────────────────────────────────────────────┘
```

## 5. 边界与不做

| 不做 | 原因 |
| --- | --- |
| 不写回 Scene/Status 到 Raindrop | 仅 Link 级别同步，Raindrop 无 Scene/Status 对应概念 |
| 不自动发现 Raindrop 账号 | 需用户手动填入 Token |
| 不作为唯一真源 | DogEar 真源（SQLite/D1）始终为权威数据源 |
| 不替代全局备份 | 备份归入备份功能设计，Raindrop 是单向通道非备份 |
