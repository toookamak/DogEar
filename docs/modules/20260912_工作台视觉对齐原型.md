# 工作台视觉对齐原型

## 1. 口径变更（用户确认）

用户在正式版部署 Cloudflare 后反馈「前端界面与原型页差异很大」，要求**按照规范和设计实现原型页的 UI 效果**。据此变更 2026-09-10 外壳屏稿的口径：

| 项 | 原口径（2026-09-10） | 现口径（2026-09-12） |
| --- | --- | --- |
| 视觉源 | `DESIGN.md` 为准，原型配色/字体**不采用** | **原型默认浅色主题为准**（`dev/dogear-workbench` 的 tokens 与组件样式） |
| 字体 | system-ui 回退 | 与原型同源 Google Fonts：Manrope（正文/UI）· Newsreader（衬线标题与大数字）· DM Mono（元信息），缺字回退系统栈 |
| 主题 | 仅浅色 | 仅浅色（不变；原型深色色板仍不采用，正式版无主题切换入口） |

**遗留冲突，待用户决定**：根目录 `DESIGN.md` 仍是 Cursor 风格规范（`#f2f1ed` 色板、CursorGothic/jjannon/berkeleyMono、hover 变 `#cf2d56` 等），与本次实施的原型暖纸色板（`#faf9f5`、Manrope/Newsreader/DM Mono、hover 加深底色）不一致。本次**未改 `DESIGN.md`、未改 `wiki/`**。若原型效果确认为长期视觉源，`DESIGN.md` 需另行修订；未修订前，界面实现以本文档 + 原型为准。

## 2. 实施范围（视觉层，不动业务逻辑）

类名体系与组件结构沿用 2026-09-10 外壳屏稿以来的成果，改动集中在 token 与 CSS：

| 文件 | 改动 |
| --- | --- |
| `apps/web/src/styles/tokens.css` | 重写。以原型默认主题为主源（`--canvas`/`--panel`/`--amber`/`--mint` 等语义名），既有 `--color-*`/`--spacing-*`/`--radius-*` 名全部保留为兼容别名并指向新语义，未重做页面与内联样式同步换肤 |
| `apps/web/src/styles/app.css` | 逐节对齐原型：赤陶橙主按钮、描边 ghost、方形 chip、琥珀 active 左条、mono 元信息、衬线标题与大数字、状态 pill 带圆点、`#` 前缀标签、空态虚线框、toast/模态/命令面板投影体系、卡片来源色（page=琥珀 / agent=薄荷 / extension=赭棕） |
| `apps/web/index.html` | 引入与原型一致的 Google Fonts 与 favicon、theme-color |
| `apps/web/src/components/bookmarks/BookmarkCard.tsx` | 重构为原型三段式：来源条（monogram/favicon + 来源 + 状态徽标）→ 装饰预览区（柔和渐变 + 斜纹 + 衬线大字水印 + 右上选择键）→ 内容区（标题 / 摘要 / 标签与信息 pill / 域名按钮）。domain 缺失时展示层从 URL 提取主机名兜底 |
| `apps/web/src/components/feedback/Skeleton.tsx` | 网格骨架与新卡片三段式同构 |
| `apps/web/src/styles.css` | 仅更新注释（视觉源说明） |

品牌标记（顶栏与登录页的赤陶橙 D 方块）以 `::before` 实现，`TopBar.tsx` 等外壳 JSX 无需改动。

## 3. 数据约束（沿用屏稿 §4/§6，不因视觉对齐放宽）

- 侧栏**统计卡与各维度计数徽标**仍不做（无工作台统计端点，禁止边写代码边加路由）；组标题旁的数字取自已加载列表的条目数。
- 状态栏仍只有「待同步数 + 撤销」；条/秒、时延、成功率、429 不展示。
- 卡片上的「重要 / 私密 / 待推送 / AI 建议」pill 为正式版真实数据，原型对应位置保留（AI 徽标即原型 `ai-badge`），不删除信息。

## 4. 验证（2026-09-12，本地）

- `pnpm --filter @dogear/web typecheck`、`build`（CSS 47.49 kB）、`test`（5 文件 68 项）全部通过。
- 本地 `wrangler dev`（模拟 D1 + `.dev.vars` 口令）+ 原型 `vite dev` 并跑，浏览器实测截图对照：登录页、工作台网格（6 条演示书签，覆盖三状态/标签/重要标记）、列表视图、看板视图、详情浮层、设置页、加载骨架。原型侧切浅色主题逐屏对照，结构、色板、字体、组件形态一致。
- 对照中发现并已修复：卡片选择键为原生 checkbox 白方块（补 `appearance: none` 与选中态背景 SVG 勾）。
- 测试数据中的中文乱码为 Windows curl 写入编码所致（本地联调数据，非界面缺陷），已用 UTF-8 请求修复。

## 5. 本批不做 / 遗留

- 不做暗色主题（原型深色色板与正式版均不启用；`tokens.css` 仅浅色）。
- 不照搬原型 `tokens.css` 的 4 套待定主题与 `app.css` 前 800 行主题占位（原型自身标注 `TODO(pending)`）。
- 未重做页面的**内联样式**（约 290 处，SettingsSection/ChannelConfig 等）本次靠 token 别名统一换肤，组件级精修留待逐页批次。
- Google Fonts 走 CDN：断网或被墙时回退系统栈（与原型行为一致）；如需强一致可后续自托管字体。
- `DESIGN.md` 与新视觉源不一致，见 §1，待用户确认是否修订。
