## 0. 问题来源

用户反馈「页面 UI 不够精细，边线、圆角、不同位置的按钮和默认样式都很简陋，像原型页」。逐行比对 `app.css`（3516 行）、`styles/tokens.css`、根目录 `DESIGN.md` 与 `docs/theme-sample-notion-cf-orange.html` 后，归为三条根因：

1. **设计源的档位没接上实现**。`tokens.css` 已定义但全仓零引用的 token 有 9 个，其中 `--radius-comfortable: 6px`（按钮/面板）与 `--radius-featured: 8px`（模态）正是 `DESIGN.md` 要求的档位 → 按钮、胶囊、输入统一停在 3px，模态停在 6px，整体比设计源低一档。
2. **没有尺寸刻度**。`app.css` 共 19 个 `font-size` 值（10–13.5px 区间挤了 8 个半像素值）；工具栏同一行控件高度 29 / 30 / 32 / 34 / 42px 五档混排。
3. **原生控件没接管**。全站 `select` 无外观重置与自绘箭头；`sidebar` / `app-content` / `detail-aside` / `palette-results` 四处滚动区无滚动条定制；图标全部是来自不同字体的 Unicode 字形。

## 1. 尺寸刻度

### 1.1 控件高度（新增 token）

| Token | 值 | 适用 |
| --- | --- | --- |
| `--control-h` | 32px | 标准控件：`.btn` 全族、`.toolbar-search`、`.filter-toggle`、`.toolbar-sort`、`.view-switcher` 外框 |
| `--control-h-sm` | 28px | 筛选胶囊 `.chip` |
| `--control-h-xs` | 24px | 行内小按钮 `.mini-btn` |
| `--icon-btn-size` | 30px | 图标按钮 `.icon-btn`（仅顶栏，与 32px 族不同屏出现） |

**规则**：同一容器内出现多个控件时，一律取同一档高度。`.view-switcher` 外框 = `--control-h`，内部 `.view-btn` = `--control-h` 减去 2×3px 内衬 = 26px。

### 1.2 字号（19 值 → 7 档）

| Token | 值 | 角色 | 收编的旧值 |
| --- | --- | --- | --- |
| `--fs-micro` | 11px | 元信息、mono、大写分组标签、脚注日期 | 9 / 10 / 10.5 / 11 |
| `--fs-small` | 12px | 次级说明、空状态文案 | 11.5 / 12 |
| `--fs-body` | 13px | 界面正文与**全部按钮** | 12.5 / 13 / 13.5 |
| `--fs-lead` | 14px | 强调正文 | 14 / 15 |
| `--fs-title-sm` | 17px | 区块标题 | 17 / 18 |
| `--fs-title` | 21px | 页面标题、详情标题、模态标题 | 20 / 21 / 22 |
| `--fs-display` | 24px | 大数字（`.stat-value`） | 24 |

装饰性字号（`.not-found-code` 72px、卡片水印 126px）不走刻度，保持绝对值。

**规则**：`--fs-body` 是按钮族唯一字号；密排 mono 元信息下限为 `--fs-micro`（11px），不再出现 10px 以下。

## 3. 交互态统一

四类状态各定一条规则，四种视图（网格 / 表格 / 看板 / 标签）与所有列表共用。

| 状态 | 规则 | 原实现 |
| --- | --- | --- |
| **hover** | 面板底转 `--panel-raised` + 边框转 `--line-strong`；**卡片族额外加 `--shadow-card` 轻投影** | 网格 / 看板 / 标签卡无投影 |
| **active**（当前项） | 橙柔底 `--amber-soft` + `inset 2px 0 var(--amber)` 左条 | 网格与看板只改边框色；表格 / 标签视图为左条 —— 四套不一 |
| **selected**（批量勾选） | 边框转 `color-mix(--amber 45%)` + 覆盖层橙柔底 | 网格为边框色；表格 / 看板为左条；标签视图无 |
| **focus-visible** | 一律 `box-shadow: var(--shadow-focus)` 橙 ring；不用浏览器默认蓝 | ring / outline / border+ring 三套混用；**`.bm-card` 漏了焦点样式（有 `tabIndex={0}` 但键盘 Tab 到无任何提示）** |

### 3.1 卡片 hover 语义（本轮裁决）

原实现「转 `--panel-raised` 灰底」在纯白页面上读作「压下」而非「浮起」，与 Notion 语义相反。改为：

- 保持 `--panel` 白底不变
- 加 `--shadow-card` 轻投影（双层：`0 1px 2px rgba(15,15,15,0.06), 0 2px 6px rgba(15,15,15,0.06)`）
- `transform: translateY(-1px)`
- 边框转 `--line-strong`

`--shadow-card` 由 `var(--shadow-lg)` 别名改为独立定义（原 `--shadow-lg` 是 14px 模糊的重投影，用作卡片浮起过重）。

### 3.2 动效时长

收敛为两档：颜色 / 边框 `150ms ease`、阴影 / 位移 `200ms ease`。原 `app.css` 有 6 种时长（0.16s×8 / 0.14s×3 / 150ms×2 / 0.18s×2 / 0.22s / 220ms），全部归入两档。

## 4. 图标规范（新增，DESIGN.md 原缺）

**结论**：不自引图标库（受 `AGENTS.md` 依赖边界约束），自写内联 SVG 组件 `apps/web/src/components/ui/Icon.tsx`。

**规格**
- 线框图标：`viewBox="0 0 16 16"`、`stroke="currentColor"`、`stroke-width="1.5"`、`stroke-linecap="round"`、`stroke-linejoin="round"`、`fill="none"`
- 实心图标（星级）：`fill="currentColor"`、无描边
- 默认 `width/height = 1em`，由外层 `font-size` 决定尺寸；随 `color` 继承
- 组件签名：`<Icon name="search" size={14} />`

**清单（替换现有 Unicode 字形）**

| name | 原字形 | 用途 |
| --- | --- | --- |
| `search` | `⌕` | 工具栏搜索、命令面板 |
| `filter` | `⚙` | 筛选按钮 |
| `grid` / `tags` / `list` / `board` | `▦ ◈ ☷ ▤` | 四种视图切换 |
| `chevron-down` | `↓`、`▾` | 下拉、排序 |
| `chevron-right` | `→` | 跳转、进入 |
| `external` | `↗` | 打开原文 |
| `close` | `×`、`✕` | 关闭、清除 |
| `star` / `star-filled` | `★` / `☆` | 收藏标星 |
| `edit` | `✎` | 重命名 |
| `arrow-up` | `↑` | 上移 |
| `command` | `⌘` | 快捷键提示（保留等宽字体渲染，不换图标） |

`.topbar-kbd`、`.toolbar-kbd`、`.palette-kbd` 内的 `⌘` / `K` 属键盘符号，**不替换**。

## 5. 原生控件接管

| 控件 | 处理 |
| --- | --- |
| `select` | `.input` 基础外观 + `appearance: none`；自绘 `chevron-down`（`background-image` 内联 SVG，`currentColor` 不适用故取 `--muted`）；右侧预留 30px 内衬 |
| 滚动条 | 全局 `scrollbar-width: thin` + `scrollbar-color: var(--line-strong) transparent`；Chromium 加 `::-webkit-scrollbar` 8px 圆角滑块 |
| `checkbox` / `radio` | 保留 `accent-color: var(--amber)`（原生勾已在各平台一致），仅统一尺寸与垂直对齐 |
| `::selection` | 新增 `background: var(--amber-soft)`、`color: var(--text)` |
| 全局 `:focus-visible` | 不设兜底（避免覆盖组件级 ring），仅要求组件自备 |

## 6. 可读性取舍

`--faint` 对白底原为 `#9f9e9b`（对比度约 2.7:1，低于 WCAG AA 正文 4.5:1），却承担全部 10–11px 元信息。本轮：

- 浅色 `--faint` 抬至 `#8a8985`（约 3.4:1）
- 深色 `--faint` 由 `#6e6e6e` 抬至 `#7d7d7d`（约 4.4:1）
- 元信息下限字号由 10px 提到 11px

**已知遗留**：浅色 `--faint` 仍低于 AA 正文标准。这是「弱化层级」与「可读性」的直接冲突，本轮选择保住层级，留待需要正式无障碍达标时再单独决策（届时需同步放宽 `--muted` / `--faint` 的间距或改用 `--muted` 承担元信息）。

## 7. 批次与验收

| 批次 | 内容 | 风险 |
| --- | --- | --- |
| 1 · 地基 | `tokens.css` 加刻度 token；`app.css` 字号改走 token | 低（纯视觉） |
| 2 · 控件 | 按钮族 / 工具栏控件统一高度与圆角；`select` 与滚动条接管 | 低 |
| 3 · 状态 | 四视图 active/selected/hover/focus 统一；过渡时长收敛 | 低 |
| 4 · 清理 | 死 token、`--radius-md` 悬空、暖白残留（`.bm-card-select` 勾形 SVG 写死 `#fff9f1`）、`--font-serif` 名实不符、图标替换 | 中（图标涉及组件改动） |

**验收口径**
1. 同一容器内控件高度完全一致（目视基线齐平）
2. 全站圆角只出现 3 / 4 / 6 / 8 / 9999 五个值，且归属符合 §2
3. 四种视图的 active 与 selected 视觉一致
4. 键盘 Tab 遍历工作台时，每张卡片都有可见橙 ring
5. `app.css` 中 `font-size` 的独立值 ≤ 9 个（7 档 + 2 个装饰值）
6. `tsc --noEmit`、`vite build`、`vitest run` 全通过

**未覆盖**：本轮不做暗色主题重新取色（仅同步 `--faint` 与 `--shadow-card`）、不做响应式断点重构、不引入图标库、不调整信息架构。
