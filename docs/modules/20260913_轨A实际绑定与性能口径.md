# 轨 A 实际绑定清单

## 1. 现已绑定

| 资源 | 配置位置 | 用途 |
| --- | --- | --- |
| Worker `dogear` | `apps/server/wrangler.toml` `name` / `main` | API + `[assets]` 同域工作台 |
| 自定义域名 `drop.861306.xyz` | Cloudflare 面板（Worker 自定义域名） | **线上入口**：<https://drop.861306.xyz/>；与 `dogear.<account>.workers.dev` 是同一份部署 |
| D1 `dogear_prod` | `[[d1_databases]]` binding `DB` | 真源库 |
| R2 `dogear-covers` | `[[r2_buckets]]` binding `COVERS`（v0.7.39） | **仅**封面缓存：D1 只存原 URL，`GET /api/bookmarks/:id/cover` 命中直接出图 |
| Workers Assets | `[assets] directory=../web/dist` | 前端静态 + SPA fallback |
| Cron `*/5 * * * *` | `[triggers]` | 消费 `sync_queue`（每批 25，与 Free 子请求配额对齐） |
| Observability | `[observability] enabled=true` | 平台日志；业务打 `dogear.request` / `dogear.sync-cron` JSON |
| Secrets | `wrangler secret put` | `DOGEAR_PASSWORD` 必填；`DOGEAR_SKILL_TOKEN` 可选 |

`run_worker_first`：**仅** `/api/*`、`/health`、`/.well-known/*`。静态路径不要扩进去。

## 2. 本期不启用（禁止擅自加 wrangler 绑定）

- KV / Queues / Durable Objects / Pages
- 把前端拆到独立 Pages 项目（会引入跨域 Cookie）
- **R2 除封面缓存外的用途**：R2 已按 v0.7.39 绑定 `COVERS`（桶 `dogear-covers`）且**仅用于封面缓存**；「快照内容入 R2」仍未做（见 `docs/TODO.md` L3），不得借该 binding 顺手存快照或其他对象

## 3. 缓存

- API：`Cache-Control: no-store`（Worker `fetch` 补头）
- `/assets/*`：`public, max-age=31536000, immutable`（`apps/web/public/_headers`，随 dist 部署）
- `index.html`：`no-cache`

## 4. 包体与运行时

- `minify = true`
- AWS SDK / csv-parse / csv-stringify：**动态 import**，未走 S3 导入导出时不进冷启动主图
- Hono `createApp`：**isolate 内缓存**，不按请求重建
- 会话 HMAC：**Web Crypto**；Skill Token 仍 `node:crypto`，故 **`nodejs_compat` 暂留**
- Cron 维持 5 分钟：比总纲「≥1 分钟」更疏，换 Free 档 CPU / 50 子请求余量

## 5. 前端加载

- 路由 `React.lazy`；Vite `manualChunks`（react / minisearch / dexie）
- 不外链 Google Fonts，系统栈回退
- 列表默认 50 条分页，600 基线靠分页而非虚拟列表（单页 50 无需窗口化）
