# 浏览器扩展与 Agent 接入

两类外部写入方共用同一条 Skill 接口，仅 `source` 不同；工作台来源条据此显示「Agent」或「插件」。

## 1. 前置：服务端配置

| 项 | 说明 |
| --- | --- |
| 地址 | Track A（Workers）为部署域名；本地联调 `http://127.0.0.1:8787` |
| Skill Token | 设置 →「Agent 接入」生成（明文只显示一次）。也可用 `DOGEAR_SKILL_TOKEN` 环境变量。未配置时 Skill 请求 401 |
| 能力开关 | 设置页 →「Agent 接入」：`read` / `write_new` / `update_existing` 三开关；扩展保存需开启「新建」 |
| 限流 | 每日读写配额（见设置页用量），超出 429 `RATE_LIMITED` |

能力自发现：`GET /.well-known/capabilities`（**无需鉴权**），返回名称、鉴权方式与技能清单。Workers 同域部署下该路径已配 `run_worker_first`，不会被前端 SPA 回退吞掉（2026-09-12 修复，见 CHANGELOG v0.7.28）。

## 2. Chrome 扩展（`apps/extension`，MV3）

代码在 `apps/extension`，无构建步骤，加载即用（安装步骤见该目录 [README](../../apps/extension/README.md)）：

1. `chrome://extensions/` → 开发者模式 → 「加载已解压的扩展程序」→ 选 `apps/extension` 目录。
2. 点扩展图标 →「去配置」→ 填 **DogEar 地址** 与 **Skill Token** → 「测试连通」（打 capabilities）→ 保存。
3. 之后任意页面点图标 → （可选填备注）→ 「保存书签」。

行为细节：

- 请求：`POST {地址}/api/skill/save_bookmark`，头带 `Authorization: Bearer <Token>` 与 `Idempotency-Key`（每次保存新生成 UUID），体 `{url, note?, source:'extension'}`。
- 幂等：同一 Idempotency-Key 24h 内重放不重复入库，返回 `replay` 标记；弹窗会提示「该链接此前已保存」。
- 保存后书签 `status=unread` 进入 Inbox，AI 建议走「输入时」落点（有建议则在弹窗提示条数，须用户到工作台确认，不自动写入）。
- 权限仅 `activeTab`/`storage`/host_permissions，不向第三方发送数据。

## 3. Agent / 第三方接入（Skill API）

```
POST {地址}/api/skill/save_bookmark
Authorization: Bearer <DOGEAR_SKILL_TOKEN>
Idempotency-Key: <可选 UUID，24h 幂等>
Content-Type: application/json

{"url": "https://example.com/article", "note": "可选备注", "intent": "可选意图", "source": "agent"}
```

- `source` 取值 `agent`（缺省）| `extension`。既有 Agent 不传 `source` 不受影响（契约向后兼容，`packages/shared` 契约测试已锁）。
- 其他可用技能见 capabilities；`update_bookmark` 默认关闭（结构变更须人工确认）。
- **已知不对称（记录在案）**：首次保存返回扁平 receipt（`{id, url, ..., suggestions}`），24h 幂等重放返回 `{bookmark: {...}, idempotent, replay}` 包裹。两者结构不一致属既有行为；修改涉及 API 返回结构变更，按仓库规则须先确认，接入方按「`data.bookmark ?? data`」兼容（Chrome 扩展已按此实现）。

## 4. 验证记录（2026-09-12，本地 wrangler dev）

- 契约测试：`@dogear/shared` 29 项通过（含新增 source 三态：缺省 undefined / extension / 非法值 400）。
- `POST /api/skill/save_bookmark` + `source:'extension'` → 201，返回 `source:"extension"`，工作台列表可见、来源条显示「插件」。
- 错误 Token → 401；`source:'page'` → 400；无 `source` → 201 且 `source:"agent"`（向后兼容）；同 Idempotency-Key 重发 → `replay:true` 包裹响应。
- `GET /.well-known/capabilities` 修复后返回 JSON（修复前被 SPA 回退吞成 index.html）。
- **未验证**：Chrome 浏览器内实际加载扩展的端到端点击（本环境无 Chrome 扩展加载自动化），按 README 手动加载即可；线上 Token 配置后的真实连通。
