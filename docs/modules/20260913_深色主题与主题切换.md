## 1. 口径依据

- `DESIGN.md` 头部主题口径（2026-09-12 用户确认）：当前默认主题（暖纸风）是**默认设置而非唯一形态**；新增主题（暗色等）时，色板、阴影乃至部分组件约束以该主题自己的定义为准（即 `DESIGN.md` §2/§6 的具体色值对深色主题不适用），结构、布局与交互语义仍全局适用。本文即深色主题「自己的定义」。
- `DESIGN.md` §9.7：新增主题 = 复制 `tokens.css` 的 `:root` 块按主题重定义值。

## 2. 机制

- **Token 层换肤**：`tokens.css` 末尾 `[data-theme='dark']` 块只重定义色值类 token（`color-scheme: dark`）；字体、间距、圆角、布局、z-index 沿用 `:root`。兼容别名层（`--color-*` 等）全部是 `var()` 引用语义层，自动随主题换肤；别名区唯一写死色值的 `--shadow-focus` 在深色块内重定义。挂载点为 `<html data-theme="light|dark">`。
- **三态偏好**：`light` / `dark` / `system`（跟随 `prefers-color-scheme`），持久化于 `localStorage` 键 `dogear.theme`。运行时模块 `src/theme/theme.ts`（纯函数：resolve / apply / set / watchSystemTheme），React 侧 `src/theme/useTheme.ts`（`useSyncExternalStore`，system 变化即时反映）。
- **首帧防闪烁**：`index.html` 内联脚本在渲染前读偏好并挂 `data-theme`、更新 `theme-color` meta（键名与两份 theme-color 值与 `theme.ts` 共用，改动需同步）。`theme.ts` 模块加载时幂等兜底一次。
- **入口两处**：顶栏 ☾/☀ 图标按钮（写显式 light/dark 偏好）；设置页新增「外观」分区（三选一分段控件，复用 `.view-switcher`，加 `--fit` 修饰保持内容宽）。
- **app.css 硬编码色清零**：原型的透明度变体（琥珀/薄荷/赭石/黛蓝边框与渐变、白斜纹、暖墨水印）全部改为 `var()` 或 `color-mix(in srgb, var(--token) N%, transparent)` 的**精确等值**形式——浅色渲染逐像素不变，深色主题自动生效。新增 token `--preview-stripe`（预览区斜纹，深色下调弱）。

## 3. 深色色板「深夜书房」

延续暖纸气质的暖黑系（值见 `tokens.css` 深色块，此处记依据）：

- 纸面：`--canvas #211e19` 黑咖底，`--panel #2a2721` 略浅一档，层级关系与浅色一致；文字用暖纸白 `#e9e3d7`（不用纯白）。
- 强调色提亮：`--amber #dd8156`；**hover 语义由「加深」改为「提亮」**（`--amber-strong #e99469`），符合深底直觉，属主题自定组件约束。
- 语义色（mint/red/blue/indigo/rust/slate）整体提亮一档；`*-soft` 底透明度 0.09 → 0.15~0.17（深底上 0.09 不可辨）。
- 阴影与遮罩改纯黑系（暖棕在深底不可辨）：`--scrim`/`--overlay-dim`/`--drawer-shadow` 黑 0.5，`--modal-shadow` 黑 0.55。
- 保留差异：`.view-btn[aria-pressed=true]` 的暖棕微阴影（`rgba(88,72,44,0.28)`）未 token 化——深色下仅弱化为不可见，不破坏视觉，留待实际需要时再处理。
